# UHD 助手

给用 UHD 系站点(自带 `/api/v1` 的订阅制媒体站)的用户,三件事合在一页:

- **流量** —— 剩余 / 已用 / 总量;站点给的是「不限流量」档时直接这么写,不画一根假的进度条。
- **求片 / 追新 / 反馈** —— 搜片名 → 点一条提交。说明是必填的(站点要求),
  已在库、不让提交的条目会标出来并给出站点说的原因。
- **线路测速** —— 32 / 64 / 100 MiB 三档,流式计字节、实时进度,结果回报给站点。
  **会真的下载数据,消耗你账户的流量。**

## 先填这三样

设置 → 插件 → UHD 助手:

| | |
|---|---|
| 站点地址 | 形如 `https://你的站点` |
| 网站用户名 | 网站账号,和 Emby 账号可能不是同一个 |
| 网站密码 | 只存在这个插件的密钥区,别的插件读不到,也不跨设备同步 |

填完从侧栏的「UHD 助手」进。

## 几件说在前面的事

- 这个插件**不声明 `lan`**:它连的是公网站点,没有访问你本机内网的本事。
- 界面上只显示线路名,**不显示线路地址**。
- 求片提交之后不能改,也没有自助删除 —— 站点没给这个接口。
- 这一版**没有投票**:站点把投票接口撤了(旧版插件里那个 `/vote` 现在不存在)。
