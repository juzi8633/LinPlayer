---
title: Live TV
---

Paste an m3u or txt playlist URL and watch. If the TVBox compatibility plugin is installed, the
live sources from its configuration show up here automatically — no need to paste them again.

## Channels

Channels with the same name are merged into "Source 1 / 2 / 3". Quality suffixes (4K, HD) are
**not** merged — those are different channels, not different links to one. When a link stalls the
player moves to the next one and remembers the one that worked, starting there next time.

Favourites, custom channel numbers, the XMLTV guide, catch-up and timeshift are all in. The guide
refreshes every six hours by default.

## Remote control

On TV it follows TVBox habits: up/down changes channel, number keys enter a channel number, OK
brings up the channel list. If you expect the opposite, turn on "Invert up/down" in settings.

## Settings

Merge same-name channels, invert up/down, guide refresh interval — three switches, all in plugin settings.
