# 插件系统决定记录(D1~D549)

> 这是 2026-09-19 ~ 09-20 与用户逐条问答拍板的**决定原文**,按编号只增不改号。
> 成体系的规格正文在 [`SPEC.md`](SPEC.md)(各章引用这里的 D 编号);API 草稿在 [`api/`](api/);逐条落点核对在 [`COVERAGE.md`](COVERAGE.md)。
> 被推翻的决定在原行直接改写成新结论并注明推翻日期,不留旧文。外部调研正本在 `docs/research/plugins-v2/`。

## 0. 原则

- **不必要的东西不内置,做成插件。** 宿主只放"插件做不了"或"所有人都要"的能力(用户 2026-09-19:"没必要内置不必要的东西到软件里面")。
