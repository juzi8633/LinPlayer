# 12. 系统集成

## 12.1 命令面板(D243 D320 D418~D419 D520 D521 D528)

- **桌面**:默认 `Ctrl+Shift+P` 调出输入框(快捷键设置里可改)。不输 `/` 时是全局搜索(搜当前服务器的片);输 `/` 开头列命令。
- **手机/TV**:在搜索页输入 `/` 进入命令模式。
- **收录**:所有有快捷键的动作 + 各页面跳转(与快捷键设置同源,不另维护)+ 插件在 manifest 声明的命令 + 「打开官方首页/详情页」(页面被接管时的出口)+ 插件的设置项(按标题/说明搜,点了跳过去)。
- 插件命令可**声明参数**并提供补全(`/直播 ` 后返回频道候选),补全 300ms 预算;同名命令都列出并标插件名,内部 id 带插件前缀。

## 12.2 按键与手势(D64 D194 D457)

- 插件可注册快捷键/遥控器按键,**可以覆盖官方按键**;插件按键与官方按键一起列在快捷键设置里,用户可改可清空。
- 两个插件抢同一键:设置里列冲突让用户选,未选前先装的生效;插件停用后被覆盖的官方按键**自动归还**。
- 手机播放页手势当作一种按键,规则相同;接管 OSD 不影响手势。

## 12.3 深链(D154 D492 D541)

| 深链 | 作用 |
|---|---|
| `linplayer://plugin/install?url=…` | 打开安装确认(D117) |
| `linplayer://plugin/repo?url=…` | 订阅仓库 |
| `linplayer://plugin/bundle?data=…` | 安装插件合集(D541) |
| `linplayer://cmd/<作者>/<名字>/<命令>?参数` | 调插件命令,只限声明 `external` 的命令;桌面命令行参数同样转成这条 |
| `linplayer://p/<作者>/<名字>/…` | 插件自定义深链,交给插件的 `deepLinks` 处理器 |
| TVBox 一键导入 | 由 TVBox 插件用自定义深链声明处理 |

桌面快捷方式(「打开直播 CCTV1」)、Android 长按图标快捷方式都落到 `cmd` 深链。

## 12.4 外部输入(D197 D304 D306 D307)

插件在 `externalInputs[]` 声明匹配规则(URL 模式 / 扩展名 / 文本正则),四种入口:

| 入口 | 说明 |
|---|---|
| Android 分享目标 | 别的 App 分享链接/文本/文件给 LinPlayer |
| 桌面拖放 | 文件或链接拖进窗口 |
| 文件关联 | 安装包**预先关联一批常见扩展名**(m3u / m3u8 / txt 直播源 / torrent / 常见视频…,官方定列表),系统里双击用 LinPlayer 打开再按规则分发;列表外的扩展名插件接不到。三端一致 |
| 剪贴板识别 | 切回应用时宿主统一按规则匹配,弹「检测到 xx,导入?」。**默认关**,设置里开;有插件声明剪贴板规则时插件详情里提示可打开(Android 12+ 每次读剪贴板系统会弹「已粘贴」) |

多个插件匹配同一输入时让用户选。插件也可以自己读写剪贴板(D197)。

## 12.5 通知(D86 D195 D547 D548)

- `ui.notify({title, body, actions?, image?})` 发系统通知;可带动作按钮(Android,D505),点了触发插件命令。
- Android 13+ 通知权限由宿主在第一次有插件发通知时申请;被拒降级成 Toast。
- **每插件每小时最多 5 条**,超出折叠成一条「xx 还有 N 条通知」(不丢)。
- 应用内不做通知中心。
- 后台发通知只限 D504 的用途(追更/开播提醒、下载完成)。

## 12.6 后台运行

见 5.11 5.12(D16 D129 D502~D509)。

## 12.7 系统能力(D196 D197 D536 D444)

`system.openUrl`(系统浏览器)、`system.openApp`(深链 / Android Intent)、`system.clipboard.read/write`、`system.share({text | url | image})`。不开放相机、语音输入、振动、独立音频播放。

## 12.8 Android 系统入口(D505 D506 D510 D511)

| 入口 | 插件怎么用 | 说明 |
|---|---|---|
| 长按图标快捷方式 | `android.shortcuts[]`(图标 + 名字 + 命令) | 走 `cmd` 深链 |
| 桌面小组件 | `android.widgets[]`(官方模板:海报行 / 列表 / 单卡片)+ `widgets.update(id, 数据)` | RemoteViews/Glance 跑不了 JSX;数据由插件在前台或后台任务里推 |
| TV 首页推荐行 | `android.tvChannels[]` + `tvChannels.publish(id, 条目[])` | 宿主自己另写「继续观看」(Watch Next) |
| 媒体通知动作 | `android.mediaActions[]`(最多 2 个) | 触发插件命令 |

## 12.9 桌面系统入口(D220 D500 D501 D507)

- 子窗口:见 7.9。
- 托盘右键菜单加项(`trayMenu[]`),点了触发插件命令;托盘始终有「完全退出」。
- `desktop.setTaskbarProgress(0~1 | null)`、`desktop.setTaskbarBadge(文字 | null)`、`desktop.setWindowTitle(文字 | null)`(传 null 恢复官方)。
- 关窗口时有后台任务:弹「退到后台 / 完全退出」+「记住我的选择」。

## 12.10 手机扫码遥控(D315 D403 D491)

宿主已有的手机扫码遥控(`core/companion`)加三件事:
- 插件声明的遥控器按钮在遥控页多一排;
- TV 输入框旁的二维码:手机扫码后在手机上打字推到 TV;
- 手机上可把插件「装到已配对的 TV」。
