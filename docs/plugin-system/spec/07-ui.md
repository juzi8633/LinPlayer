# 7. UI 系统

## 7.1 写法与渲染路径(D23 D44)

插件用 **JSX + Preact** 写 UI;SDK 自带渲染器,把组件树变成 JSON 交给两端**原生**渲染。插件拿不到官方页面源码,「在官方基础上改」= 用官方镜像出来的组件重新拼(D44)。

```
插件运行时(goja)                           Go 核心               壳(Avalonia / Compose)
Preact ──► SDK 最小 DOM(记录变更)──► ops ──► plugin.ui 事件 ──► 渲染器按帧应用 → 原生控件
  ▲                                                                     │
  └──────── 回调执行 ◄── plugin.ui.event 命令 ◄───────── 用户交互 ◄──────┘
```

- SDK 内置一个最小 DOM 实现(只有 `createElement/appendChild/insertBefore/removeChild/setAttribute` 这一级),Preact 在它上面渲染;每次变更记成一条 op。这样 Preact 本体不改,Hooks、Context、Fragment、key 全部原样可用。
- 不做「整页 HTML/CSS」模式(D270)。要网页用 `<WebView>` 组件。

## 7.2 Surface

每块插件 UI 挂在一个 **surface** 上:插件页、锚点区块、首页栏目、覆盖层、侧栏标签、设置区块、子窗口、OSD 都是 surface。壳在需要时请求核心层挂载(`plugin.ui.mount {slot, props}`),拿到 `surfaceId`;卸载时 `plugin.ui.unmount`。

| surface 种类 | 挂载时机 | 卸载时机 |
|---|---|---|
| page | `nav.push` 进栈 | 出栈(在栈里保活,D133) |
| block(锚点/首页栏目/设置节) | 所在官方页渲染;锚点区块的 props 是当前条目的完整统一数据(D160) | 所在官方页销毁 |
| overlay / global overlay | 播放页出现 / 应用启动 | 播放页离开 / 插件停用 |
| panel(播放页侧栏标签) | 用户切到该标签 | 侧栏关闭 |
| osd | 播放页按 scope 选中该插件 | 播放页离开 |
| window(桌面子窗口) | `ui.openWindow` | 窗口关闭 |

首帧出来前壳显示官方通用骨架屏(D271)。

## 7.3 渲染协议

**核心 → 壳**:事件 `plugin.ui`,一帧一条(D318:16ms 内的所有变更合成一个 patch,壳一帧只重排一次):

```jsonc
{"surface":"s7","frame":42,"ops":[
  {"op":"create","id":12,"type":"PosterCard"},
  {"op":"props","id":12,"set":{"title":"三体","onPress":{"$fn":31}},"unset":["subtitle"]},
  {"op":"insert","parent":3,"id":12,"before":15},     // before 为 null = 追加
  {"op":"text","id":20,"value":"第 1 集"},             // 文本节点,只能在 Text 下
  {"op":"remove","id":9},                             // 连同子树
  {"op":"canvas","id":40,"cmds":[["fillRect",0,0,10,10], …]}
]}
```

- 首帧就是从根开始的一串 `create/props/insert`。
- 函数属性序列化成 `{"$fn": 回调号}`;回调号在该 surface 内有效,属性更新时旧号作废。
- 未知组件(老宿主遇到新组件)画成「需要更新 LinPlayer」小块,未知属性直接忽略,开发者模式报 warn(D319)。

**壳 → 核心**:命令 `plugin.ui.event {surface, fn, args}`;核心投进插件循环执行回调,回调预算 1 秒(D53)。

**节流**(D135):滚动、拖动类事件每帧最多一条;输入框默认**非受控**——原生自己维护文字,只在 `onChangeText` 防抖后与 `onSubmit` 时通知 JS;要逐字响应显式声明 `live`。

## 7.4 组件

**全部官方页面用到的组件都镜像开放**(D41 D44)。分两层:

| 层 | 组件(初版) |
|---|---|
| 原语 | `View` `Row` `Column` `Stack`(叠层)`ScrollView` `Text` `Image` `Icon` `Pressable` `Button` `TextInput` `Switch` `Checkbox` `Slider` `Select` `Divider` `Spinner` `Skeleton` `VirtualList` `VirtualGrid` `Canvas` `Player` `WebView` `Markdown` |
| 业务 | `PosterCard` `PosterRow` `PosterGrid` `EpisodeGrid` `LineTabs` `DetailHeader` `FilterPanel` `ProgressBar` `ServerCard` `Chip` `ChipGroup` `Tabs` `SettingsGroup` `SettingsRow` `EmptyState` `Badge` `RatingList` |

- 业务组件与官方页面**同一份原生实现**,主题改它们,插件里的也跟着变(D21)。
- 组件清单与属性随 SDK 发布(`api/plugin-sdk.d.ts` 的 `components` 声明);新增组件属于次版本。
- 列表项要求 `key`,缺了用下标并在开发者模式报 warn(D218)。
- 所有组件有 `a11yLabel`,映射到 Avalonia `AutomationProperties` / Compose `semantics`;文字类组件默认用自身文字(D445)。

### 7.4.1 特殊组件

- **`<Player>`**(D268 D276):全局只有一个 mpv 实例;放了 `<Player>` 就把视频层定位到这块区域;点全屏进官方播放页**不断播**;所在页被返回或跳走时停播并记住进度,不做悬浮小窗。桌面视频是独立子窗口,壳要做区域跟随(待 spike,D268)。
- **`<WebView>`**(D269):显示网页,插件可注入 JS、与页面互发消息;不可用的机器显示「不可用」。
- **`<Canvas>`**(D19 D104 D105):API 仿 HTML5 Canvas 2D(fillRect / fillText / path / drawImage / 变换 / 渐变);每帧的绘制调用录成指令流一次性发给原生端画;`requestAnimationFrame` 按设备能力限到 30/60fps,超时降帧不卡 UI。离屏画完导出 PNG 用 `canvas.renderToPng`(D536)。
- **`<VirtualList>` / `<VirtualGrid>`**(D134):插件给 `itemCount` + `renderItem(i)` + `onEndReached`;原生端只向 JS 要可见范围(`plugin.ui.range {surface, list, from, to}`),SDK 只渲染这一段并回收离开的项。
- **`<ProgressBar>`**(D161 D163 D562):不给 `value` 时绑当前播放进度,原生直接读 mpv、不过 JS,自带预览缩略图(Emby trickplay / 数据源给的 / 预览图提供者的);给了 `value`(0~1)就画插件自己的进度。`seekable` 只对绑 mpv 的那一种有意义。

## 7.5 样式与布局(D89 D90 D91)

RN 式 `style` 对象,属性集合是我们定义的子集,两端都能映射:

| 类 | 属性 |
|---|---|
| 布局(Flex 子集) | `direction` `justify` `align` `gap` `grow` `shrink` `basis` `wrap` `width` `height` `minWidth` `maxWidth` `minHeight` `maxHeight` `padding*` `margin*` `position`(`relative`/`absolute`)`inset` `top` `left` `right` `bottom` `zIndex` `aspectRatio` |
| 外观 | `background`(颜色/渐变)`opacity` `radius` `borderWidth` `borderColor` `shadow` `backdropBlur`(玻璃)`overflow` |
| 文字 | `color` `fontSize` `fontWeight` `fontFamily` `lineHeight` `textAlign` `maxLines` `letterSpacing` |
| 图片 | `fit`(`cover`/`contain`/`fill`)`tint` |
| 变换 | `translateX` `translateY` `scale` `rotate` |
| 动效 | `transition` `animation`(见 7.6) |

- 布局映射:Avalonia `StackPanel`/`Grid`/`Canvas`,Compose `Row`/`Column`/`Box`(D91)。
- 数值单位是设备无关像素。
- **任意值**都可以写;官方的圆角/间距刻度只约束官方代码(D89)。
- 引用主题 token 写字符串 `'token:名字'`,如 `{ radius: 'token:radius.card', color: 'token:color.accent' }`,跟随主题切换(D89)。token 名清单见 20.4(D556),随 SDK 发布。

## 7.6 动效(D88 D428)

- 属性变化动画声明 `transition: { props: ['opacity','translateY'], duration: 200, easing: 'standard' }`,**由原生端跑,不过 JS 桥**。
- 关键帧动画声明 `animation: { keyframes: [...], duration, iterations }`。
- 官方组件自带动效原样保留。逐帧动画走 Canvas。
- 系统开了「减少动态效果」:transition 与关键帧由原生端直接跳到终态;Canvas 不管,插件读 `app.reducedMotion` 自己决定。

## 7.7 响应式、主题与安全区(D217 D425 D426 D558)

- `useViewport()` 给宽高、官方断点(`compact` / `medium` / `expanded`,与官方页同一套)、`insets`、形态(`desktop` / `phone` / `tv`);变化时重渲染(节流到帧)。视口是**按 surface** 分帐的 —— 同一个插件的页和侧栏区块本来就不一样大。
- `useTheme()` / `useReducedMotion()` 吃的是**应用级**环境:壳用 `plugin.setEnv` 报明暗、token 表(20.4)与系统「减少动态效果」,切一次主题报一次,变了所有挂着的 surface 重渲染。和 `plugin.setCapabilities` 分开报 —— 能力一辈子不变,环境每次切主题都变(D558)。
- SDK 里声明的 hooks **必须全部挂上**,门禁比对 `.d.ts` 与运行时(D555);依赖尚未实现的命名空间的那些,调用时当场抛清楚的错误,不返回 `undefined`。
- **TV**:插件页宿主默认加安全边距(与官方 TV 页同一套);全屏类页面声明 `edgeToEdge` 铺满。
- **手机**:默认避让刘海/挖孔/手势条;声明铺满时自己按 `insets` 让。

## 7.8 焦点与键盘(D31 D424 D529)

- 可点组件默认可聚焦;方向键交给平台原生(Compose 焦点系统 / Avalonia 键盘导航)。
- 插件可覆盖:`focusable` `autoFocus` `focusGroup`(组内方向键移动)`nextFocusUp/Down/Left/Right`(指向 key)。
- TV 上返回插件页时宿主按组件 key **恢复上次焦点**。
- 桌面同一套:可点组件进 Tab 顺序、回车触发、方向键在焦点组内移动。
- TV 输入框:系统输入法 + 手机扫码输入(输入框旁显示二维码,手机打字推过来);不做官方屏幕键盘(D315)。

## 7.9 页面、导航与页面选项

- **导航栈**:插件页与官方页共用一个栈;`nav.push(路由, 参数)`,路由是官方路由名或 `作者/名字:页面id`;返回键/遥控器 Back 统一宿主处理(D84)。插件也能跳官方页(如打开某部片详情)。
- **页面保活**:在栈里的插件页不销毁,返回后原样(D133)。
- **返回拦截**:只限插件自己的页面(「表单未保存,确定离开?」)(D85)。退出播放永远由宿主兜底(D459)。
- **页面选项**(D219):标题、全屏/沉浸(隐藏侧栏与状态栏)、横竖屏锁定、屏幕常亮;离开页面自动恢复。
- **导航拦截器**:见 6.3。
- **子窗口**(D220 D500):桌面可开独立窗口(弹幕姬、节目单),可置顶、无边框、透明背景、鼠标穿透、记住位置大小;Linux Wayland 下做不到的能力由能力探测返回不可用;手机/TV 降级为整页。

## 7.10 反馈组件(D86 D416)

`ui.toast`、`ui.confirm` / `ui.prompt` / `ui.select`(对话框)、`ui.notify`(系统通知,见 12.5)、`<Skeleton>` 加载态、`<EmptyState>`(一句话 + 一个去处按钮,不配插画)。

## 7.11 错误边界(D136 D452)

每个 surface 是一个错误边界:渲染或回调抛错,只在那块显示「xx 插件出错 [重试] [禁用]」;接管位的 surface 崩了自动回退官方页面;开发版显示红色错误覆盖层。

D136 说的「**区块级**」就是这一级:7.2 里 `block`(锚点 / 首页栏目 / 设置节)本身是一种 surface,不是「surface 里的某棵子树」(D557)。

## 7.12 性能目标(D543)

- TV 上 1000 项 `VirtualList` 连续滑动 ≥ 50fps;
- 插件页首帧 < 300ms(从 `nav.push` 到首帧上屏,插件已加载的前提下);
前两条是第 ② 阶段的验收线。另有一条实现目标(不算验收,只在开发者模式报 warn):每帧 patch 在壳 UI 线程上的应用时间 < 4ms。
