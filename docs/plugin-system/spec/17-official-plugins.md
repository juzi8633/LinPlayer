## 17.1 TVBox 兼容(`linplayer/tvbox`)

### 能力范围(D7 D24 D100~D103 D114 D348 D532)
- 站点:type 0(XML 苹果CMS)、type 1(JSON 苹果CMS)、type 3 JS spider(drpy 系)、type 3 jar(`csp_`)、Python spider、type 4 远程 HTTP 接口(T4)。
- 整份配置导入,订阅式;解析接口(parses)type 0/1/2/3 与 jar 类(含神解析,随 jar 环境);WebView 嗅探;直播源(`lives`)交给直播插件;rules / ads 去广告。
- **非媒体的 http 播放地址一律当网页处理(D576)**:先抓页面抠出 m3u8 / mp4(带 Range 封顶),再走配置的解析器,最后才是 WebView 嗅探。「不像网页就直接播」会把一段 HTML 交给播放器。
- **顶级分类要展开成子分类再查(D575)**:苹果 CMS 的顶级分类是空壳,片子挂在子分类上;按 `type_pid` 建树,查顶级分类时把子分类 id 用逗号连起来。拿不到 `type_pid` 的站,空分类要说清楚为什么空。首页没有推荐时退回第一个有内容的分类。
- **不是标准形状的配置也要认回来(D573)**:裸站点数组(外面没有 `{"sites":…}`)、站点不写 `key`(按 name / api 哈希补)、直接粘进来的配置内容(不是地址)、ForwardWidget 的 `.fwd` 小组件清单(抠出每个小组件里的采集站)。认不出来时报错要说清它**是什么**,不能导入「成功」而 0 个源。
- 用户手写的 drpy 规则作为单个数据源(D120)。
- 不做 DoH,忽略 `doh`;忽略 `notice` `wallpaper` `logo`;忽略 `changeable` `style` `playerType`;源级 `timeout` 生效;全局 `flags` 照 TVBox 语义(D103 D347 D440)。

### 贡献点
- `dataSource.serverTypes`:「TVBox 订阅」(表单:配置地址**或配置内容**,多行 → 壳给「从文件读入」,见 12.4)、「drpy 规则」(表单:规则文本或地址)。
- `deepLinks`:一键导入 TVBox 配置;`externalInputs`:分享/拖放/剪贴板里的 TVBox 地址。
- `m3u8Filters`:配置自带的 rules / ads(D238)。
- `registry.channels`:写 `live.channels` `live.epg`,推荐读者 `linplayer/live`(D275)。
- `playerPanels`:「解析」标签(D377)。`pages`:解析管理页。
- `settings`:订阅刷新间隔、嗅探超时、启用配置自带去广告规则、jar/py 运行环境管理(D378)。
- `requires.components`:`jar-runtime` `python`(按需)。

### 订阅流程(D45 D46 D100 D230 D231 D345 D346 D379)
1. 用户贴地址 → 拉取 → 解码:按影视仓/FongMi 的顺序依次识别 图片尾部藏 JSON、base64 前缀、AES 加密(含 URL 里 `;pk;` 给的密钥)、JSON5(注释、尾逗号)。解码不出来报 `parseFailed` 并写明卡在哪一步。
2. **多仓**(`urls` / storeHouse):列出各仓让用户勾选,每个勾选的仓成为一个独立订阅(一个分组),多仓地址本身也记住,仓列表变了提示。地址里嵌套的 GitHub 加速代理前缀(`https://代理/https://raw…`)要能处理。
3. **拆源**:一个配置拆出多个源,让用户勾选;不支持或本设备跑不了的源(没装 jar 环境、桌面 jar spike 未通过)**灰显并写原因**,顶部一句「共 N 个源,M 个在本设备不可用」(D351)。
4. 默认「允许聚合」跟随 `searchable`(D235)。
5. **刷新**:默认每次启动一次 + 运行中每 24 小时(用户可调);只在应用运行时(不走后台,D504)。新增源自动加入并显示;删掉的源记录保留;刷新失败沿用上次成功副本并 Toast 原因。服务器列表订阅分组菜单:立即刷新 / 编辑地址 / 重新勾选源 / 删除订阅;手机下拉刷新全部。
6. 添加时:一次性免责提示(D523);配置含直播源而没装直播插件时提示一次(D275)。

### 源的执行
| 类型 | 怎么跑 |
|---|---|
| type 0/1 | 插件主运行时直接 `fetch` 苹果CMS 接口,转统一结构 |
| drpy(JS) | 引擎用配置指定的 drpy2(按 md5 缓存),拉不到用内置实测版兜底;依赖库(cheerio / crypto-js / jsencrypt / gbk / 模板)插件内置,`js.bundle` 按 `assets://` 解析;每源一个子运行时,按需建、闲置回收,TV 同时最多 4 个、桌面 16 个(D316 D530 D531) |

内置的那一份**不入库**:`drpy2.js` 的可执行代码里有第三方 OCR 服务的域名与端口,
注释里还有私网 IP 和样例私钥。`scripts/fetch-drpy.sh` 按 sha256 现拉,
**上游地址写在脚本里**(公开开源项目钉在某个提交上的 raw 地址,D571)——
藏进 Secret 的代价是漏配的那次 CI 静默失灵,而红线要挡的不是这一类。
| jar / py | `spider` 宿主能力(5.10);jar 按 md5 缓存(D352) |
| type 4 | 按约定参数请求远程 HTTP 接口拿 JSON(D532) |
| `ext` 远程地址 | 拉取并按订阅周期缓存,拉不到用上次缓存(D533) |

### 转换规则
- `vod_*` → 统一结构(D254);`vod_remarks` → `remarks`(D330);`vod_play_from` / `vod_play_url`(`$$$` 与 `#` 分隔)→ `lines[]` / `episodes[]`,线路名优先用站点给用户看的名字(如「星空线路」),实在取不到才用内部代号(D331)。
- 分类 `filters` 全是单选(D334);分类海报比例插件按经验声明(D336)。
- 简介里的广告尾巴按规则去掉(宿主只去 HTML 标签,D462)。

### 播放与解析(D58 D59 D115 D257 D374 D377 D440)
- `play()` 返回最终地址。线路在 `flags` 里或返回 `parse=1` 时走解析链:按用户在解析管理页排好的顺序逐个试,失败换下一个;type 0 解析走 WebView 嗅探。
- 嗅探:隐藏 WebView 加载、拦截请求抓 m3u8/mp4,默认 15 秒抓不到就跳整页 WebView 让用户过验证/点播放。
- 解析管理页:增删、排序、测试;解析列表不跨设备同步(D325)。
- 播放页侧栏「解析」标签显示当前解析,可手选另一个重试。

### 错误映射
403/验证页 → `needVerify`;429 → `rateLimited`(带 `Retry-After`);连接失败/5xx → `siteDown`;规则执行异常 → `parseFailed`;空结果 → `notFound`。

## 17.2 直播(`linplayer/live`)

**总原则**:TVBox 怎么操作直播源,我们就怎么操作(按键、手势、菜单习惯照搬)(D356)。直播不当服务器:侧栏独立「直播」入口,所有直播源汇总在一个直播页,不随服务器切换(D110)。

### 数据(D43 D108 D111~D113 D274 D465 D466 D468 D470 D495 D534 D535)
- 来源:直播页贴 m3u/txt 地址或本地文件、注册表 `live.channels`(TVBox 配置的 lives)、其它插件写的频道源。代理直播(`proxy://do=live…`)走 jar 环境,没有环境的设备灰显。
- 频道级请求头:m3u 的 `http-user-agent` `http-referrer` 与 `#EXTVLCOPT`。
- 同名频道按归一化名合并,各源地址进「源 1/2/3」;归一化**保留清晰度后缀**(4K/8K/高清 不合并);频道长按「拆开此频道的源」;设置里合并总开关。
- EPG:XMLTV / DIYP,插件自己在 JS 里流式解析、落盘;多源按优先级取第一个有数据的;每次启动 + 每 6 小时刷新,缓存 3 天,只在应用运行且打开过直播时拉。
- 台标:`tvg-logo` > EPG icon > 文字台标(频道名前两字)。
- 回看/时移:append / shift / default(`${start}` `${end}` 等模板)/ flussonic。
- 手动一键检测:并发探测,失效的标灰并排到该频道源列表后面。

### 播放(D61)
播不了或卡顿超过 8 秒自动切下一个地址;播放页可手选「源 1/2/3」;记住每个频道上次能用的地址。

### 界面(D357 D358 D467 D471 D360)
- **TV**:进来全屏播上次频道;确认键从左侧滑出「分组 / 频道 / 节目单」三栏,左右键在栏间移动;上下键直接换台(「上」= 上一个频道,可反转,D359);数字键输频道号(右上角大字);换台显示信息条 3 秒(台标 + 频道号 + 频道名 + 当前/下一个节目 + 源 1/2/3);返回键:有列表先关列表,再按提示「再按一次退出」,两秒内再按才退出。
- **桌面**:左侧分组 + 频道,右侧 `<Player>` + 下方节目单,点全屏进官方播放页。
- **手机**:竖屏上方播放、下方频道列表,横屏全屏。
- **回看/时移入口**:节目单里点已播节目(显示「回看」标,从头播)、直播进度条往回拖(「回到直播」跳回)、暂停后从暂停处接着播。
- OSD:声明 `osd` scope = `live`,不影响点播(D297)。

### 个人化(D109 D469)
收藏频道(置顶分组)、最近观看、可设「启动直进直播」(启动页接管位,D130)、隐藏分组/频道、拖动排序、频道搜索、自定义频道号。遥控器按钮:上/下一频道(D491);Android TV 推荐行可放收藏频道(D505)。

## 17.3 Trakt/Bangumi 同步(`linplayer/sync`)(D363 D365)

账号登录与 token 在宿主(18.2),插件经 `trakt.request` / `bangumi.request` 代发。全三层,只去掉「播完评分弹窗」:

1. **进度**:监听播放事件,Trakt 用 Scrobble(start / pause / stop 带真实百分比,≥80% 由 Trakt 判看过);Bangumi 播完达阈值时先把条目设为「在看」再标单集。
2. **状态展示与开关**:设置里各服务器同步开关(用 `servers.list()` 选「只同步哪几台服」);详情页锚点注入「Trakt 已看 / Bangumi 在看 5/12」。
3. **收藏管理**:想看单/收藏管理、吐槽、标签、批量集数进度、看到最后一集自动标「看过」。

条目对应:优先用统一结构里的外部 id(TMDB/IMDB/Bangumi),没有再按片名搜索并让用户确认一次、按剧记住。

## 17.4 字幕翻译(`linplayer/subtitle-translate`)(D364 D487~D489)

- **取原文**:`player.getSubtitleText(轨道)`;没字幕时可用 `player.transcribe()`(Whisper 组件)先转写。
- **引擎**:OpenAI 兼容接口、Anthropic 接口、百度翻译、腾讯翻译(都用用户自己的 key,存密钥区)、免费机翻(不稳定、可能被封)。
- **管线**(照搬旧实现已验证的做法):分块 → 并发翻译 → 失败二分重试,单条失败回退原文 → 全部失败要报错(不能静默交出一份没翻的字幕)→ 译文贴回**对应那一条**(贴错 = 整轨错位)→ 输出 SRT(原文 / 译文 / 双语三种排版)→ `player.addSubtitle`。大模型引擎每批 ≤40 条、≤4000 字、并发 3;百度每批 ≤50 条、≤2000 字。
- **实时模式**:订阅 `sub-text` 边播边翻一句一句显示在覆盖层。
- 结果按「源字幕 + 引擎 + 语言 + 排版」缓存在插件 `cache/`。

## 17.6 规则编辑器(`linplayer/rule-editor`)(D121 D368)

给懂 drpy 的人,不做表单向导:
- 一个源码编辑器页(语法高亮用 `<WebView>` 里的编辑器或原生多行输入,插件自定)。
- 「测试」按钮:在自己的子运行时里跑 home / category / detail / play,显示结果或报错栈。drpy 引擎与依赖库**打包进本插件**(与 TVBox 插件同一份源码,打包时各自带上,D17),不去调 TVBox 插件。
- 「保存为数据源」:`nav.push('server.add', { type: 'linplayer/tvbox:drpy-rule', prefill: { rule } })` 打开官方「添加服务器」页并预填,由 TVBox 插件的「drpy 规则」服务器类型承载(D120)。没装 TVBox 插件时提示去装。

## 17.7 UHD 助手(`linplayer/uhd`)(D581)

给用 UHD 系站点(自带 `/api/v1` 的订阅制媒体站)的用户:**流量 / 求片 / 测速**三合一。
旧栈是三个各自独立的插件,同一套网站账密要填三遍、存三份;合成一个之后账号只填一次。

- **站点地址、用户名、密码全在插件设置里**,代码里一个都没有(仓库红线)。密码与登录
  token 走 `secrets`(系统密钥库),不进普通存储。
- **不声明 `lan`**:它连的是公网站点,不该有翻本机内网的本事。
- 端点(2026-09-21 在真站上逐个实测,见 `docs/lessons/plugins.md`):
  `auth/login`(裸 token,不是 Bearer)· `traffic/me`(带「不限流量」标记)·
  `users/me` · `media-requests/search|topics/list|mine/list` + 创建(说明必填)·
  `subscriptions/domains` → `/{id}/resolve` → 线路上的 `speed-test/session|download`
  → 主站 `speed-test/report`。
- **旧插件里的「全部求片」`media-requests/list` 现在是 404**,站点换成了话题广场
  `media-requests/topics/list`;投票接口整个没了 —— 所以这一版没有投票。
- 测速:大小只收 32/64/100 MiB,`download` 的 `size_mb` 必须等于会话的 `size_mib`
  (对不上服务端只回几十字节,分段下载就是这么废掉的)。**前 300 毫秒 / 1 MiB 算热身不计平均**,
  否则测出来的数比真实带宽低一截。界面上**只显示线路名,不显示线路地址**。
