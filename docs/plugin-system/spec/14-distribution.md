# 14. 分发与插件页

## 14.1 四种分发(D9)

订阅仓库地址、官方市场、本地文件/扫码、开发模式(本地目录 + `lp dev` 推送)。

## 14.2 仓库与 index.json(D28 D118 D119 D182 D240 D241 D481)

- 一个仓库 = 任何静态托管上的一个 `index.json`(格式见 `api/index.schema.json`)。
- **官方市场**就是一个预装、不可删的默认订阅,格式与用户订阅的仓库完全一样;浏览页合并展示所有订阅并标来源。
- 条目要点:`id` `name` `description` `i18n` `repository` `icon` `screenshots` `readme`(官方仓库 CI 生成的静态副本地址)`paid` `platforms` `requires` `contributes`(贡献点摘要,用于分类与清单)`stars`(官方仓库 CI 抓,第三方仓库没写就不显示)`downloads` `versions[]`(每版 `version` `url` `size` `minAppVersion` `released` `changelog` 摘要)。
- 多个仓库里同 id 的插件合并成一条(显示最高版本,官方来源优先),展开看各来源;已装的仍只认安装来源(D48)。
- 客户端不直连 GitHub API(未认证 60 次/小时/IP)。
- `minAppVersion` 写的是**这个包真能跑起来的最低版本**,不是「上架时的当前版本」(D568)。
  官方插件用 2.0.0 的插件系统,写 `1.1.0` 等于让老版本看见一个装了必坏的插件。

## 14.3 下载与离线(D370 D371)

- 直连优先;失败时自动套用户在设置里填的 GitHub 加速前缀重试;**不内置任何镜像地址**;跟随应用代理。
- 市场拉取失败/离线:显示上次缓存的市场 + 横条「市场列表更新失败,显示的是 N 天前的」;已装插件照常用。

## 14.4 插件页(D221~D224 D388~D391 D416)

入口:设置里一项 + 命令面板,不占侧栏,用户可自己固定到侧栏。插件页本身**永远官方**,不可接管(D29)。

顶部四个标签:

**已安装**
- 每项:图标 / 名称 / 版本 / 作者 / 来源(+ 官方标记)、启用开关、状态(正常 / 已自动禁用及原因 / 有更新 / 待重启 / 开发版)。
- 排序:有问题的在前(已自动禁用 / 有更新 / 待重启),其余按名称。
- 「全部更新」:并发下载,全部装完弹一次「是否重启立即生效」,失败的单独列出。
- 「一键全部禁用」:记住之前的启用状态,可一键恢复(重启生效)。
- 空状态:「还没有安装插件 [去市场]」。

**市场**
- 搜索(名称/描述/作者)、分类(按贡献点从 manifest 自动推出:数据源 / 主题 / 播放器 / 弹幕字幕 / 工具…,作者不用填)、排序(下载量 / 最近更新 / star / 新上架)、只看官方、含付费功能显示/隐藏;平台按当前设备自动过滤(D239 D138)。
- 不设官方推荐位(D202);不做评分评论(D240)。
- 插件详情:截图、README 渲染、更新日志、下载量、star、**贡献点清单**(会接管哪些页、注册哪些键、加哪些数据源……)、支持平台 / 必需能力 / 所需扩展组件 / minAppVersion、历史版本、同作者其他插件、「含付费功能」标记、包大小(D79 D142 D402 D409)。
- 版本不兼容:显示但按钮变「需要升级 LinPlayer」(D450)。
- 空状态:「没找到「xx」[清除搜索]」。

**接管位**
- 每个接管位一个下拉(官方 / 插件 A / 插件 B…):首页、各被接管的官方页、播放控制栏(各 scope)、主题、壁纸、启动页、排行榜页、下一个播什么、被替换的锚点区块、着色器链。按键冲突仍在快捷键设置里选(D64)。

**仓库**
- 订阅仓库地址增删(官方市场不可删)、GitHub 加速前缀、自动更新开关(D49)。

**插件详情页(已装)**(D224 D437 D448 D449 D283 D503)
- 设置(manifest 自动生成,或插件自己的 JSX 设置页)、贡献点清单、占用 + 清缓存/清数据、启动耗时(超 500ms 标黄)、更新日志、回退上一版 / 选历史版本 / 跳过此版本 / 解锁自动更新、单独关掉悬浮层、单独关后台任务、导出设置、卸载、反馈。

## 14.5 安装与更新流程

见 4.6。补充几个界面:
- 安装确认(本地/扫码/非官方仓库):贡献点清单 +「非官方来源」+ 需要的扩展组件 + 是否访问局域网 + 大小(D117 D381 D247 D142)。
- 更新确认:更新日志摘要(index.json 自带,不用先下包)+「这次新增」的贡献点(D182 D446)。
- 改动离开插件页或退出时:「插件有改动,重启后生效」[立即重启 / 稍后] (D170)。

## 14.6 免责提示(D408 D523)

各一次性,措辞以免责为主、不咄咄逼人:
- **首次打开市场**:插件由第三方开发维护,官方不对插件内容负责。
- **添加第三方仓库时**:同上,并提示该仓库不是官方维护。
- **添加 TVBox 订阅时**:内容由用户自行订阅,与官方无关。

## 14.7 TV 上装插件(D413 D403)
