# 9. 播放器扩展

视频层不动(D14);插件能读写 mpv、换控制栏、加覆盖层与侧栏、挂着色器,但拿不到带 token 的地址(第 3 章 E2 E3)。

## 9.1 属性、命令与事件(D32)

- `player.get(属性)` / `player.set(属性, 值)` / `player.command(命令, ...参数)` / `player.observe(属性, 回调, {hz})`:**任意 mpv 属性与命令透传**。
- **脱敏清单**:`path` `stream-open-filename` `http-header-fields` `playlist` 及 `playlist/*` `stream-path` `working-directory` 读出来是脱敏值;`loadfile` `loadlist` `playlist-*` 类命令对插件不开放。清单放在核心层一处常量,随版本维护,门禁测试覆盖。
- **事件**(D94 D161):播放生命周期(开播/暂停/恢复/缓冲/播完/切集/出错)、音轨与字幕轨变化、OSD 显隐、画中画进出(D458)。状态变化时宿主推送;进度这类高频值要自己画就订阅限频的 `time-pos`(默认 4Hz,上限 10Hz)。
- **单帧截图**:`player.screenshot()` 拿 `screenshot-raw` 的一帧像素(PNG);不能流式逐帧取(D106)。
- **播放**:`player.play(itemId | 统一条目)` 由宿主取流(D95);`player.playUrl(地址, 请求头, {title, poster, recordKey})` 播任意地址,进官方播放页,给了 `recordKey` 才记进度与历史(D310)。

## 9.2 改动记账与还原(D33 D299 D301 D302)

宿主给每个插件记一本账:它改过的每个属性「改之前的值」、它挂的着色器与滤镜。

- 同一属性被多方改(插件之间、插件与用户设置)时**后写生效**;开发者模式可看到最后是哪个插件改的。
- 插件改的属性一直生效到插件停用,不按集自动还原。
- 插件停用/卸载时,把它改过的每个属性**还原到它改之前的值**,不管之后有没有被别人改过(已知可能冲掉用户后来的手动调整);撤掉它挂的着色器与滤镜。

## 9.3 着色器与滤镜(D32 D107 D298)

- 画面处理一律走 mpv 着色器(`glsl-shaders`)与滤镜(`vf`/`af`);覆盖层只画 UI,不碰视频像素。
- 插件在 manifest `shaders[]` 声明着色器组(名称 + 包内 `.glsl` 文件),出现在「画面增强」选择里。
- **全局只有一条着色器链**:官方画面增强档位、插件 A、插件 B 多选一;选一个时提示「开启后将关闭 xx」,用户确认才切。
- 这条规则也管插件用 `player.set('glsl-shaders', …)` 直接改的情况:宿主把它视为「选中了该插件的链」并走同样的提示。

## 9.4 播放控制栏(OSD)接管(D14 D67 D161 D162 D297 D457 D459)

- `osd[]` 贡献点声明适用范围:`vod` 点播 / `live` 直播 / 某个来源(开放键或 `emby`)/ `embedded`(自己 `<Player>` 里);每个范围各是一个接管位。直播插件的换台 OSD 不会替换点播的。
- 插件 OSD 是一个 surface,拿到状态推送;进度条用官方 `<ProgressBar>`(原生绑定,不过 JS)。
- 显隐由宿主按官方规则管(鼠标静止隐藏、触摸唤出)并告知插件;插件可声明自己管显隐(如常驻进度条)。
- 官方把字幕 / 音轨 / 倍速 / 画面增强 / 弹幕 等菜单做成**可调用的子面板**:`player.openPanel('subtitles')`;插件 OSD 放个按钮即可。插件没放的,用户仍能用快捷键/长按菜单唤出。
- 手势属于播放页不属于 OSD:接管 OSD 后官方手势仍在,插件要改走手势注册(D194)。
- 退出播放由宿主兜底:返回键 / Esc / 遥控器 Back 永远可退(D459)。
- Android 画中画时插件 OSD 与所有覆盖层隐藏,只留系统小窗控件(D458)。

## 9.5 覆盖层与侧栏(D65 D279 D300)

- 播放覆盖层默认点击穿透,声明 `interactive` 才拦截点击与遥控器焦点。
- 播放页侧边面板(选集/字幕/音轨那栏)可加插件标签(图标 + 名字 + JSX),如评论、剧情说明、节目单、解析(D377)。

## 9.6 下一个播什么(D244 D460)

播放结束时宿主问 `nextUp` 接管位的插件「下一个播什么」(随机、跨季连播、播放列表);返回统一条目就播它,返回空就停;没人接这个位走官方规则(数据源:同线路下一集,见 8.7)。

## 9.7 字幕相关

- 字幕显示改动走 `sub-*` 属性透传;插件不能自己渲染字幕(D164)。
- **字幕全文**:`player.getSubtitleText(轨道)` —— 宿主带 token 拉取字幕轨全文(含 Emby 内封字幕导出),返回文本与格式(D487)。
- **实时字幕行**:订阅 `sub-text` 属性(D487)。
- **挂字幕**:`player.addSubtitle(文件或文本, {lang, title, select})` → 宿主存进字幕缓存再 `sub-add`(D164 D188)。
- **Whisper 转写**:`player.transcribe({ lang, model })` —— 宿主用 ffmpeg 组件抽当前条目音频(用带 token 的流地址,只能宿主做),交 whisper 组件转写,返回字幕文本;两个组件都是扩展组件,用到时提示下载(D488 D380)。进度通过回调推送。

## 9.8 抽帧(D538)

`player.extractFrames(条目, 时间点[], {width})` —— 宿主用 ffmpeg 组件带 token 取流、在指定时间点抽帧,返回图片。给「进度条预览图提供者」用;插件自己决定间隔、缓存、是否预生成。

## 9.9 投屏与下载

- `cast.open()` 弹官方设备选择,投当前正在播的;插件拿不到设备列表与投出去的地址(D311)。
- `download.enqueue(itemId)` 让官方下载器下 Emby 片,与官方下载按钮同一道权限门,该用户没有下载权限就抛 `permission`(D309)。

## 9.10 媒体通知动作(D511)

手机锁屏/通知栏媒体卡片:插件可加 1~2 个自定义动作(「跳过片头」「下一频道」),触发插件命令;播放/暂停/进度仍官方。
