# 10. 提供者

提供者给官方功能供数据:界面、缓存、合并规则都是官方的,插件只实现接口。

## 10.1 弹幕源(D56 D66 D184~D186 D248~D250 D386 D432~D434)

**接口**:`match(线索) → 候选[]`、`load(候选, 时间窗) → 弹幕[]`、可选 `send(候选, 弹幕)`。

- **线索**(D185):片名、年份、季/集号、外部 id(TMDB/豆瓣/Bangumi)、文件名、时长、文件哈希(有时有)。
- **匹配**:宿主按片名 + 集数自动选最佳候选;错了用户手动纠正,纠正结果按整部剧记住(D56)。
- **分批交付**(D186):宿主按时间窗向插件要弹幕,插件按**条数**控制每批大小(高潮段落自动切小窗口),防单批过大卡住。建议每批不超过 3000 条。
- **合并**(D184):官方弹弹 Play 与所有插件源合并渲染,按「时间 + 文字」去重;数据源 `play()` 自带的弹幕作为这一集的一个源、默认开(D433)。
- **设置**(D386):弹幕设置里「弹幕源」列表 —— 官方弹弹 Play 与各插件源并列,每源有开关、当前匹配结果、手动纠正入口、**时间偏移 ± 秒**(按源分别调、按整部剧记住,D432);屏蔽词、密度、字号等全局设置对所有源生效。弹幕过滤由宿主做,不开放过滤插件(D66)。
- **失败**:匹配失败/超时/限流时播放页 Toast 提示一次(按错误类型出文案),详细状态在弹幕源列表(D434)。
- **发送**(D248~D250):用官方输入框(颜色/位置);发送时选目标站 = 实现了 `send` 的源;发出后立刻本地显示并加高亮边框,不等回包;失败 Toast 并标记该条;没有任何源支持发送时不显示输入框;**TV 上不能发弹幕**。
- **第三方站点登录**(如 B 站)插件自己做:WebView 或自绘表单,凭据存密钥区;官方不做统一账号中心(D68)。

## 10.2 字幕(D73 D187 D188 D387)

**接口**:`search(线索 + 用户字幕语言偏好) → 候选[]`(名称/语言/格式/评分)、`download(候选) → 字幕文件`。

- 字幕菜单「在线搜索」列出各插件结果,**按插件分组**、谁先返回先显示,组内按插件评分与语言偏好排序;用户手选。
- 用户可开「没有字幕时自动挂最佳匹配」。
- 下载到的字幕存宿主字幕缓存,按条目记住「这集用了哪个在线字幕」,下次播放自动挂上。
- 字幕翻译插件走另一条路:取原文(9.7)→ 翻译 → `player.addSubtitle`。

## 10.3 元数据(D74 D76 D192 D193 D435 D436)

**接口**:`lookup(条目) → 部分字段`,声明模式 `supplement`(补充展示)/ `override`(覆盖 Emby 元数据,只在本地显示,不写回)/ `complete`(补全数据源元数据),模式由插件自己声明。

- **调用时机**:打开详情页时按需调用,结果按条目缓存 7 天;详情页更多菜单「刷新元数据」;列表与海报墙不逐项调。
- **多个插件冲突**:设置里拖动排序,靠前覆盖靠后,**按字段生效**(A 没给简介就用 B 的)。
- **评分**是带来源名的列表,各家**并排显示**(带小图标、可点跳网站),不按优先级覆盖。
- **换图**:按覆盖模式可替换海报/背景图,只在详情页生效,海报墙仍是 Emby 原图。
- **搜索别名**:插件可提供「中文名 → Emby 条目」映射,存本地,搜索时一并匹配。

## 10.4 下载后端(D25 D77 D78 D189~D191)

**接口**:`submit(地址, 请求头, 文件名) → 任务 id`、`status(id)`(进度/速度/状态)、`pause` `resume` `remove`、完成后可选返回可播 URL。

- 点下载时选「用哪个下载」,默认官方,可设默认后端;插件任务也进官方下载列表统一显示进度;宿主定时轮询 `status`(前台 2 秒一次;后台见 5.12)。
- **Emby 的片只能用官方下载器**(不把带 token 的地址交给插件);外部后端只用于数据源的片与插件自己的链接(磁力等)。数据源的片不进官方下载器。
- 外部下载完成后插件返回可播 URL,进官方「已下载」列表直接播。
- 多份配置(两台 aria2)插件自己在设置里管(D171)。

## 10.5 片头片尾(D537 D342)

**接口**:`segments(条目) → {introStart?, introEnd?, outroStart?}`。优先级:Emby 自带标记 > 用户手设(数据源按剧的 N 秒)> 插件提供。结果交官方跳过功能。

## 10.6 进度条预览图(D163 D538)

**接口**:`thumbnails(条目) → { interval, tiles }` 或按需 `thumbnailAt(条目, 秒)`。Emby 已有 trickplay/BIF 时优先用 Emby 的;数据源可在 `PlayResult` 里直接给预览图地址;插件为 Emby 片生成预览图时用宿主抽帧 API(9.8)。

## 10.7 直播频道源与 EPG(D108 D112 D237 D272 D274 D495)

不是贡献点而是**注册表通道**(直播是官方插件,不是宿主功能):

- `live.channels`:频道源。条目 = 一份频道列表(分组、频道名、台标、tvg-id、地址[]、请求头、回看模板),或一个 m3u/txt 地址由读者去拉。TVBox 插件把配置里的 `lives` 注册进来;用户在直播页贴的地址由直播插件自己管。
- `live.epg`:EPG 源。条目 = XMLTV / DIYP 地址或已解析的节目数据。四路来源:m3u 头 `x-tvg-url`、TVBox `epg`、用户手填、插件提供;同一频道多源都有数据时按优先级取第一个有数据的(用户手填 > m3u 头 > TVBox > 插件),频道长按可指定。
- 解析 XMLTV/DIYP 由直播插件自己在 JS 里做(流式、自己落盘),宿主不内置 EPG 解析。
