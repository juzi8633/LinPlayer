# 13. 存储、同步与备份

## 13.1 三类存储(D38 D143 D144 D284 D417)

| | KV | 私有文件 | 密钥区 |
|---|---|---|---|
| API | `storage`(同步) | `files.data` / `files.cache` | `secrets` |
| 放什么 | 设置之外的小数据、缓存索引 | `data/`:要留的文件;`cache/`:可随时丢的(jar、海报、EPG) | Cookie、token、密码、API key |
| 物理位置 | 宿主数据库里每插件一张表 | `<数据根>/plugins/<作者>/<名字>/data|cache/` | 系统密钥库(Windows DPAPI / Android Keystore / Linux Secret Service;没有时退回应用密钥加密文件) |
| 配额 | 无 | 无 | 无 |
| 一键清理 | 清数据 | cache 可单独清 | 清数据时一起清 |

- 插件设置项(manifest 声明的)存在宿主设置表里,不占插件 KV;密码/密钥类设置项的值存密钥区(D267)。
- 数据全局一份,不按 Emby 账号隔离;要区分用 `servers.current()`(D417)。
- 插件详情显示占用(KV + data + cache),可一键清缓存/清数据(D143 D224)。

## 13.2 跨设备同步(D137 D140 D325 D339 D527)

| 同步 | 不同步 |
|---|---|
| 装了哪些插件、从哪装(另一台设备提示「要装这 N 个插件吗」,不支持该平台的跳过) | 插件启用状态、接管位选择 |
| 插件 KV(按键记修改时间,后写覆盖)与 `data/` | `cache/` |
| TVBox 订阅 + 源列表设置(勾选、排序/隐藏、允许聚合、手改 host) | 解析接口列表(各设备各管) |
| 数据源收藏、观看记录与进度 | 插件密钥区 |
| 搜索历史 | — |

## 13.3 备份(D139 D325 D490)

备份沿用 `core/config/backup.go` 的容器,新增 `linplayer_plugins` 段:

| 内容 | 「只备份设置」档 | 「带账号」档 |
|---|---|---|
| 已装插件清单(id + 来源 + 版本) | 进 | 进 |
| 本地文件装的插件包本身(没处重下) | 进 | 进 |
| 市场/仓库装的插件包 | 不进,恢复时重新下载 | 同左 |
| 插件 KV 与 `data/` | 进 | 进 |
| 插件设置 | 进 | 进 |
| 插件密钥区 | **不进** | **进**(与 Emby token 同进同出,UI 已有「文件里带着凭据」警示) |
| TVBox 订阅、数据源收藏与记录、搜索历史 | 进 | 进 |

## 13.4 分享

- **插件合集**:把一组已装插件导出为合集(小 JSON:插件 id + 来源),生成深链/二维码;对方一次确认装全部,非官方来源照 D117 告知(D541)。
- **插件设置**:插件详情「导出设置」为文件/二维码,导入到同一插件;**密钥区永不进分享**(D542)。

## 13.5 卸载与删除(D38 D272 D333)

- 卸载弹窗「同时删除数据」默认勾:删 KV、`data/`、`cache/`、密钥区、插件设置;不勾则全部保留,重装后回来。
- 无论勾不勾:注册表里它写的条目清掉;它改过的 mpv 属性与着色器还原;它的接管位回退官方。
- **宿主数据不随插件删**:数据源的收藏与观看记录永远保留(灰显「来源已移除」)。

## 13.6 旧插件系统遗留(D324)

2.0.0 首次启动时静默删除旧插件系统留在磁盘上的数据(已装旧插件、其设置);升级弹窗里加一句「旧插件已移除」。
