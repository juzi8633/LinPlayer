# 18. 宿主侧变更

插件系统之外,宿主本身要改的东西。

## 18.1 排行榜、付费追剧日历回宿主(D361 D362 D366 D200 D228)

2026-09-19 本地提交 `6b290d80` 把排行榜、追剧日历连同字幕翻译、Trakt/Bangumi 同步一起删了。后两者改做插件;**排行榜与付费追剧日历改回宿主内置**:它们要用弹弹 Play 签名与 TMDB key,做成插件就得走 CF 中转,后期 CF 配额不够。

恢复范围(从 `6b290d80^` 取回,逐项对等验收,D545):

| 恢复 | 来源 |
|---|---|
| `core/ranking/`(弹弹动漫榜 + TMDB 影视榜) | `git show 6b290d80^:core/ranking/…` |
| `core/sync/` 中的**账号连接**(Trakt 设备码 / Bangumi OAuth、token 刷新)、`calendar.go`、`afdian.go` | 同上;scrobble 相关(`trakt.go` `bangumi.go` 的同步部分)不回宿主,移入 `linplayer/sync` 插件 |
| 桌面 `RankingPage.cs` `CalendarPage.cs`、Android `DiscoverPages.kt`、TV `DiscoverPage.kt` | 同上 |
| 编译期密钥 `TMDB_API_KEY`(以及日历用到的 `LP_BANGUMI_REDIRECT_URI` `LP_AFDIAN_SPONSOR_URL`)、`sealsecrets` / `secrets.go` 的对应字段、`build.yml` 三个构建 job 的传参、`check-workflows.sh` 闸门、`BUILD-SECRETS.md` | 同上 |

新增:
- 排行榜加 **Bangumi 榜**(公开 API,不需要密钥)。
- 排行榜页是接管位,官方榜是默认项,插件可整页替换(D75)。
- 追剧日历:已在用户 Emby 媒体库里的集标「已入库 / 可播」,点了直接播;**开播提醒**:追的剧有新集发系统通知,应用没开时走后台任务(宿主自己的后台任务,规则同 5.12)。
- 付费追剧日历照旧走自建代理 verify 订单号,**只在解锁时校验一次**;凭据 = 校验通过的订单号,存核心层偏好 `calendar_unlock_order`,三端共用。未解锁**锁整页、连数据都不拉**(D551)。
  老用户已解锁状态**不沿用**(D550 推翻 D228):旧记录在已删的 Tauri WebView localStorage 里,重输一次订单号。

## 18.2 Trakt/Bangumi 账号连接在宿主(D199 D203 D204 D365)

- 登录与 token 刷新在宿主,追剧日历直接用;同步插件经 `trakt.request` / `bangumi.request` 借用(宿主带 token 发,插件看不到)。用户只登一次。
- OAuth 走自建中转:优化中转网页,用户**在我们的页面上**登录;client secret 只在中转服务端。桌面/手机:本机浏览器跳转 + `linplayer://` 回调;TV:设备码(二维码 + 短码,手机/电脑上完成,应用轮询拿 token)。
- 中转对所有插件开放(`oauth` 命名空间),第三方插件也能用我们的应用身份做其它站的 OAuth;已知风险:被滥用时应用身份可能被上游封。
- **连接入口三端都要有**(D569)。`6b290d80` 把同步移出宿主时连入口一起删了,只剩 TV 还有 ——
  而同步插件里写着「到设置里的账号页连一次」,在桌面和手机上指向一个不存在的地方。
  桌面在「设置 → 常规」,手机在「设置 → 其它」,都照 TV 那份:Trakt 设备码、Bangumi 粘令牌。

## 18.3 留在宿主的功能(D125)

直播、TVBox 兼容层、去广告、调试面板、字幕翻译、Trakt/Bangumi 同步(scrobble 与收藏管理部分)。「影视目录」页连同 `source.Cataloger` 抽象已删(D126),服务器图标库保留。

## 18.5 扩展组件页(D380~D382)

设置里新增「**扩展组件**」页,统一管理宿主可下载的大件原生运行物:

| 组件 | 用途 | 平台 |
|---|---|---|
| 补帧(已有) | RIFE/DRBA | 桌面 |
| `jar-runtime` | 桌面跑 TVBox jar(JVM + dex 转换 + 安卓 API 桩) | 桌面(待 spike) |
| `python` | TVBox Python spider | 全部 |
| `geckoview` | 系统 WebView 缺失/过旧时的内核 | Android(待 spike) |
| `whisper` + `ffmpeg` | 本地转写、抽音频、抽帧 | 桌面(手机按实测再定) |

- 每项显示是否已装、大小、谁在用(哪些插件声明需要),下载/删除/更新。补帧原入口保留并跳到这里。一套下载管理代码(照补帧组件做法:可复现 zip,见 `scripts/pack-interp-runtime.py`)。
- 组件独立版本号,启动时检查,有新版亮红点、用户点才更新;应用升级需要新版组件时才强制提示。
- 插件用到时(`ext.ensure('python')`)宿主弹下载确认,不在安装时强制下。

## 18.6 Android TV Watch Next(D510)

宿主自己把 Emby 与数据源的「在看」写进 Android TV 启动器「继续观看」,播放进度变化时更新。

## 18.7 老用户迁移(D227 D229 D324)

- VERSION 升 **2.0.0**;在此之前不发正式版(避免「功能删了、插件还没有」的空窗)。
- 2.0.0 首次启动:静默删除旧插件系统的磁盘数据;对老版本用过字幕翻译、登录过 Trakt/Bangumi、或装过旧插件的用户**弹一次**「插件系统已重做:字幕翻译、Trakt/Bangumi 同步改为官方插件 [去安装]」,并附一句「旧插件已移除」。没用过的不弹。

## 18.8 宿主新增的通用能力清单

插件系统要求宿主新增、且与插件无关也有用的能力,实现时各自成块:

- 全局命令面板(12.1);
- 剪贴板识别(默认关,12.4);
- 文件关联(安装包预关联扩展名,12.4);
- 桌面托盘与「退到后台」(12.9);
- 换源(8.8)与「允许聚合」开关;
- 选集正序/倒序(D332,Emby 剧集页同样适用);
- 全局「全部收藏」汇总页(D326);
- 搜索历史全局一份(D339);
- 壁纸模糊度/压暗设置(D442)。
