# 4. 插件包与生命周期

## 4.1 插件包 `.lpplugin`(D26 D142 D421)

单个 zip,扩展名 `.lpplugin`,大小不限(市场与安装确认页显示大小)。

```
alice-douban-1.2.0.lpplugin
├── manifest.json        必需,源码根目录原样打进来(D264)
├── main.js              必需,lp build 产物:单文件 ES2017 IIFE(D145)
├── main.js.map          可选,开发与报错栈映射(D81)
├── CHANGELOG.md         建议,完整更新日志(D182)
├── README.md            可选;市场展示用的是官方仓库 CI 生成的静态副本(D481)
├── icon.png / icon.svg  商店图标,PNG/WebP/SVG,建议 256×256(D183)
├── icon-mono.svg        入口小图标,单色 SVG(D549)
├── assets/…             任意资源:图片、字体(D71)、着色器、drpy 库
└── theme/…              主题文件(桌面 .axaml 或手机/TV JSON,D214 D215)
```

包内资源经数据通道 `/p/<token>/<插件id>/<路径>` 访问,插件代码用 `assets.url('assets/x.png')` 拿地址。

## 4.2 id 与版本

- **id** = `作者/名字`(D47),两段都只许小写字母、数字、连字符(D265),正则 `^[a-z0-9]+(-[a-z0-9]+)*/[a-z0-9]+(-[a-z0-9]+)*$`。
  官方插件作者名固定为 `linplayer`(D266)。进官方索引时 CI 校验作者名 = PR 提交者 GitHub 用户名;自建仓库与本地文件不校验。
- **版本**强制 semver(D180),不合法拒装。更新判断、回退、同 id 比较都按 semver。预发布后缀不特殊处理(D181):`1.3.0-beta` 就是一个比 `1.2.9` 大、比 `1.3.0` 小的普通版本。
- **minAppVersion**(D36 D411):`lp build` 按所装 SDK 版本自动填,SDK 版本号 = 应用版本号。宿主版本低于它时,市场显示但按钮变「需要升级 LinPlayer」;已装插件的新版不兼容时不提示更新,安装时取能兼容的最高版本(D450)。
- 不承诺 API 兼容,破坏性变更直接改,写进 SDK CHANGELOG(D36 D526)。

## 4.3 manifest.json

完整字段与校验规则以 `api/manifest.schema.json` 为准,这里讲语义。

| 字段 | 必需 | 语义 | 出处 |
|---|---|---|---|
| `id` `name` `version` `description` | 是 | 见 4.2;`name`/`description` 是插件写什么显示什么 | D39 D400 |
| `i18n.en.name` `i18n.en.description` | 否 | 只给市场与 Pages 站用 | D400 |
| `main` | 否 | 入口,默认 `main.js`;纯主题包可以没有 | D206 |
| `icon` `iconMono` | 否 | 商店彩色图标 / 入口单色 SVG(没给就用首字母圆形) | D183 D549 |
| `screenshots` | 否 | 截图,全部可选 | D373 |
| `minAppVersion` | 是 | `lp build` 自动填 | D411 |
| `platforms` | 否 | `windows` `linux` `android` `android_tv`;不写 = 全平台;市场按当前设备过滤 | D138 |
| `requires.capabilities` | 否 | 必需能力(`webview` `canvas` `shaders` `touch` `tv` …),不满足的设备市场不显示 | D179 |
| `requires.components` | 否 | 需要的宿主扩展组件(`jar-runtime` `python` `geckoview` `whisper` `ffmpeg`),安装页列出,用到时才下 | D381 |
| `lan` | 否 | 会访问局域网;没声明就拦截 | D247 |
| `paid` | 否 | 含付费功能,市场标注 | D409 |
| `homepage` `repository` `issues` `license` | 否 | `issues` 用于「反馈」按钮;`repository` 进官方索引时必须是公开仓库 | D172 D408 D483 |
| `activation.load` | 否 | `startup` 启动即加载 / `lazy` 用到才加载(默认) | D51 |
| `activation.lifetime` | 否 | `resident` 常驻到退出(默认) / `idle` 闲置回收 | D51 |
| `contributes` | 否 | 全部贡献点,见第 6 章;其中 `settings[]` 声明的设置项由宿主自动生成设置页,复杂设置可换成插件自己的 JSX 页(`settingsPage`) | D34 D35 D267 |

**manifest 与代码一一对应**(D206):`contributes.pages[].id = "channel"` 就要求 `definePlugin({ pages: { channel: … } })` 里有同名实现。`lp check` 与市场 CI 都查这一条(D483 D484);运行时缺实现的贡献点按错误边界处理。

## 4.4 入口文件

```ts
import { definePlugin } from '@linplayer/plugin-sdk'
export default definePlugin({
  activate(ctx) { /* 注册运行期资源,读设置 */ },
  deactivate() { /* 可选:清理 */ },
  pages: { … }, dataSource: { … }, commands: { … }, providers: { … }, hooks: { … }, …
})
```

一个对象导出全部贡献点实现,TS 全类型检查(D206)。完整类型见 `api/plugin-sdk.d.ts` 的 `PluginDefinition`。

## 4.5 状态机

```
            安装                 启用(重启后)            首次用到/启动即加载
[未安装] ─────────► [已装·停用] ◄──────────► [已装·启用] ───────────────────► [已加载] ──activate──► [活动]
                        ▲    停用(重启后)          ▲                          │  闲置回收(idle)
                        │                          └──────────────────────────┘
        连错 5 次/10 分钟 │ 内存看门狗销毁运行时(仍是启用,下次用到重建)
        自动禁用(立即) ──┘
```

- **改动的生效时机**:安装、更新、卸载、启用、停用都**重启后生效**,可以批量改(D170)。用户离开插件页或退出程序时弹「插件有改动,重启后生效」[立即重启 / 稍后]。插件列表对这类插件显示「待重启」(D221)。
- **更新**完成后单独弹一次「是否重启软件立即生效」(D169);「全部更新」装完只弹一次(D391);自动更新静默下载、下次启动生效、不弹窗(D540)。
- **重启之后**按启动页设置进入,不恢复原页面(D539)。
- **例外**:开发版插件改文件立即热重载(D451);切换壁纸不用重启(D441);主题切换要重启(D69)。
- **自动禁用**是立即的:同一插件 10 分钟内连续报错 5 次(超时、未捕获异常、钩子超时、内存看门狗销毁都计入),立即停用并提示原因(D53)。连错计数只数连续的,一次成功调用清零。
- **加载时机**(D51):默认用到才加载、常驻到退出;`startup` 的插件在启动后**并行**加载,首屏不等(D439)。例外:接管了首页的插件,首页等它,先显示骨架屏,超 3 秒本次回退官方首页。插件详情显示启动耗时,超 500ms 标黄(D437)。
- **闲置回收**:`lifetime: idle` 的插件 5 分钟没有任何调用就销毁运行时(页面在导航栈里、后台常驻服务运行中不算闲置)。

## 4.6 安装、更新、回退、卸载

- **安装确认**:本地文件、扫码、非官方仓库安装先显示贡献点清单 +「非官方来源」,确认才装(D117);需要的扩展组件列为「可能需要下载:xx(约 N MB)」(D381);声明了 `lan` 的写明「会访问局域网」(D247)。
- **带接管位的插件**:装完(重启后)问一句要不要启用;同一插件有多个接管位时**一个弹窗列全部**,默认全勾、可逐项取消(D116 D513)。
- **来源**:记住安装来源,只从那里更新;其它仓库的同 id 显示「已安装(来自其它仓库)」,要换来源先卸载(D48)。
- **更新**:全局「自动更新」开关默认关;关着时启动检查、有新版亮红点、用户点才装(D49)。可「跳过此版本」(D449)。
  新版新增贡献点(新接管位、新声明局域网)时,更新确认里列出「这次新增」,新接管位不自动生效;自动更新遇到这种变化暂停等用户确认(D446)。
- **设置项**:更新后同名设置保留,其余丢弃,不提供迁移钩子(D447)。
- **回退**:更新时保留上一版包;新版连崩被自动禁用时一键回退(D50)。另可在插件详情选**任意历史版本**安装,装旧版后该插件锁定不自动更新直到用户解锁(D448)。
- **卸载**:弹窗勾选「同时删除数据」(默认勾),不删则重装后数据还在(D38)。插件卸载不影响宿主数据:数据源的收藏与观看记录永远保留(D333)。注册表里该插件写的条目清掉(D272)。它改过的 mpv 属性与着色器还原(D33)。

## 4.7 防崩三件套与安全模式(D12 D376)

1. **单次调用超时中断**:见 2.3.1。
2. **连续报错自动禁用**:见 4.5。
3. **连崩安全模式**:宿主启动时写「启动中」标记,应用稳定运行 30 秒后清除。连续 2 次启动都没清掉标记(= 连崩 2 次),第 3 次启动进**安全模式**:把全部插件置为停用,弹一次「上次启动连续崩溃,已关闭全部插件。最可疑:xx 插件(崩溃前最后在跑的)」[去插件页];插件页顶部横条保留到用户开过任一插件。没有手动进入安全模式的入口。
   主题加载失败(D372)回退官方主题并计入这里的连崩判定。

## 4.8 错误的呈现

- **区块级错误边界**(D136):某个插件区块渲染或回调崩了,只在那块显示「xx 插件出错 [重试] [禁用]」;接管位崩了自动回退官方页。
- 开发版插件出错显示红色错误覆盖层,带映射回 TS 的栈(D452)。
- 每个错误提示都有「复制错误详情」和「反馈」(打开 manifest 的 `issues`);详情里带该插件最近 500 条日志与最近 200 条网络请求(内存,不落盘);**不自动上传任何东西**(D172 D285 D456)。

## 4.9 开发版(D42 D292 D451)

开发版 = 桌面「加载本地目录」或 `lp dev` 推送来的插件。与正式版同 id 时开发版优先:正式版挂起、数据共用,列表标「开发版」;断开推送或移除目录后恢复正式版。开发版改动即时热重载:deactivate → 重新执行 main.js → activate,插件页按原参数重开,KV 不动。主题改动不热重载(D69)。
