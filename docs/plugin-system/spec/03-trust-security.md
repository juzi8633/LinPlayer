# 3. 信任与安全

## 3.1 信任模型:完全信任(D5)

装了即全权限:不弹权限框、不做沙箱拦截、不限频(D252)、不设存储配额(D143)。
安装时的「贡献点清单 + 非官方来源」提示只是**告知**,不是授权(D117)。

理由:插件的价值在于自由度,而权限系统在明文 JS + 完全可改的开源客户端里挡不住有心人,只会挡住正常作者。

## 3.2 例外清单(完全信任下仍然守住的东西)

全部例外只围绕一件事:**Emby 凭据不外泄**;外加一条防呆的局域网声明。

| # | 守什么 | 怎么守 | 出处 |
|---|---|---|---|
| E1 | Emby token / 密码 | 宿主 API 不返回;图片地址不带 `api_key` | D11 D92 |
| E2 | 带 token 的流地址 | 插件拿不到 Emby 片的流地址,播放走 `player.play(itemId)` | D95 |
| E3 | mpv 里会暴露地址的属性 | `path` `stream-open-filename` `http-header-fields` 与 playlist 相关属性读出来是脱敏值;屏蔽清单随版本维护 | D32 |
| E4 | 账号 / 服务器 / 代理设置 | 对插件不可写 | D93 |
| E5 | 凭据相关页面 | 添加服务器、登录、账号设置、网络代理设置:不可整页接管、不可被导航拦截器改路、不开放锚点、全局悬浮层在这些页自动隐藏 | D407 D29 |
| E6 | Emby 片下载 | 只能官方下载器;插件可 `download.enqueue(itemId)` 但拿不到地址,且与官方下载同一道权限门(`Policy.EnableContentDownloading`) | D190 D309 |
| E7 | Emby 只读代发 | `emby.request` 只许 GET;响应里 token、带 api_key 的地址、流地址、服务器地址类字段(`LocalAddress` `WanAddress` `RemoteEndPoint` 等)脱敏;取流/下载/转码类端点拒绝 | D472 |
| E8 | 服务器信息 | 只给 id(跨设备稳定的哈希)+ 显示名 + 类型;不给用户名与地址 | D287 |
| E9 | Trakt/Bangumi 账号 | 登录在宿主,插件只能经 `trakt.request` / `bangumi.request` 代发,看不到 token | D365 |
| E10 | 需要 token 的宿主操作 | 字幕全文、Whisper 转写、抽帧都由宿主带 token 取流后把**结果**给插件 | D487 D488 D538 |
| L1 | 局域网访问 | manifest 声明 `lan: true` 才能访问私网地址(RFC1918、链路本地、`localhost` 除宿主自身路由外);没声明就拦截并报错。这是运行时唯一拦截 | D247 |

**E5 为什么必须有**:没有它,插件接管登录页或把用户导到一个仿冒登录页,就能直接拿到 Emby 密码,E1~E4 全部白做。

**E3 的脱敏值**:读 `path` 得到 `linplayer://redacted`,其余属性返回空串或空数组;写这些属性的命令(`loadfile` 等)对插件不开放 —— 插件要播放只能用 `player.play` / `player.playUrl`(D310)。

## 3.3 安装器底线(D421)

不是权限,是防坏包:
- 拒绝 zip 里含 `../` 或绝对路径的条目;
- 解压后总大小超过 2GB,或整体压缩比超过 100 倍,拒装;
- `manifest.json` 缺失、不是合法 JSON、`version` 不是 semver(D180)、`id` 不合规则(D265),拒装。

## 3.4 本地监听

- 插件**不能自己监听端口**(D246),要给播放器喂数据走宿主代理路由(D498)。
- 宿主代理路由带随机会话 token(D499);唯一无 token 的是 jar 兼容入口,它**只监听本机回环**(D353)。
- `lp dev` 推送要手动打开并用 6 位配对码配对,退出应用即关闭(D291)。

## 3.5 明确接受的风险

写下来,免得后人当成疏漏去「修」:

| 风险 | 为什么接受 |
|---|---|
| 桌面 `.axaml` 主题能实例化任意控件,等于跑原生 UI 代码 | 完全信任(D214) |
| 自建 OAuth 中转对所有插件开放,被滥用时应用身份可能被上游封 | D204 |
| 插件命名通道让插件之间形成数据依赖 | D273 |
| 「官方插件」识别是软识别(明文 JS) | D205 |
| 付费追剧日历、插件自己做的付费解锁都是软锁 | D200 D409 |
| 插件停用还原 mpv 属性时可能冲掉用户后来的手动调整 | D302 |
| 编译期密钥(弹弹、TMDB)是混淆级,拿到发行包就能提取 | D361,`core/secrets` 注释 |
| 备份文件「带账号」档包含 Emby token 与插件密钥区,混淆级加密 | D490 |
| 官方市场不做逐版审查,已上架作者的更新 CI 校验通过就自动合并 | D290 D294 |
