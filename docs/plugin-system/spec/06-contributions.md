# 6. 贡献点总表

所有贡献点都在 `manifest.json` 的 `contributes` 里声明(D34),在 `definePlugin` 里实现(D206)。宿主不执行代码就能:列出插件会做什么(安装确认、市场详情、D79 D117)、列出冲突与设置项、在用到时才懒加载插件。

贡献点按**多个插件同时存在时怎么办**分四类:

| 类别 | 同时多个时 | 用户在哪管 |
|---|---|---|
| **接管位** | 同一时刻只生效一个,冲突时用户选(D15);默认官方 | 插件页「接管位」标签(D222) |
| **注入位** | 全部生效,按规则排列 | 各自的排序/隐藏设置 |
| **钩子** | 串联或「第一个生效」,顺序用户拖(D280);单个出错或超 300ms 跳过(D281) | 设置里的钩子顺序列表 |
| **提供者** | 全部生效,结果合并或并列 | 对应功能的设置(弹幕源列表、元数据优先级…) |

## 6.1 接管位

| 接管位 | manifest 键 | 说明 | 出处 |
|---|---|---|---|
| 任意官方页面整页 | `pageTakeovers[]`(`target` = 官方路由名) | 首页、详情页、媒体库、搜索、设置各页、排行榜页…;**插件管理页与凭据页不可接管**;被接管后命令面板里仍能打开官方版 | D29 D75 D320 D407 |
| 被替换/隐藏的锚点区块 | `anchors[]` 中 `mode: replace/hide` | 同一锚点多个插件抢 = 接管位 | D159 |
| 播放控制栏(OSD) | `osd[]`(`scope`:`vod` / `live` / 某个来源 / `embedded`) | 每个 scope 各是一个接管位 | D14 D297 |
| 主题 | `theme` | 分端,切换重启生效 | D69 D210 |
| 壁纸 | `wallpaper` | 叠在任意主题上,切换不重启 | D441 |
| 启动页 | `launchTargets[]` | 「启动时打开」可选首页 / 上次页面 / 插件声明的页 | D130 |
| 下一个播什么 | `nextUp` | 播放结束时宿主问插件;没人接走官方规则 | D244 |
| 着色器链 | `shaders[]` | 全局只有一条链:官方画面增强、插件 A、插件 B 多选一,切换时提示「开启后将关闭 xx」 | D298 |

**启用时的询问**:装完带接管位的插件,重启后问要不要启用;同插件多个接管位一个弹窗列全部、默认全勾(D116 D513)。接管位选择不跨设备同步(D527)。

## 6.2 注入位

最初拍板的四类注入位是侧栏入口、首页栏目、详情页区块、右键/更多菜单(D30),后来按需扩成下表。

| 注入位 | manifest 键 | 排列规则 | 出处 |
|---|---|---|---|
| 侧栏入口 | `sidebar[]` | 可排序/隐藏/固定;插件入口超过 2 个默认收进「更多」,可关收纳;可加角标 | D158 D305 |
| 插件页面 | `pages[]` | 通过侧栏、命令、深链、`nav.push` 打开 | D84 |
| 首页栏目 | `homeSections[]`(`kind: items` 返回条目 / `custom` 自画) | 与官方栏目一个列表拖动排序、可隐藏;新装追加到末尾 | D156 D303 |

| 详情页四个快捷位置 | `anchors[]` 用 `detail.title` 等预置锚点 | 同上 | D155 |
| 官方设置页一节 | `settingsSections[]`(声明式设置项或 JSX 区块) | 标题标明来自哪个插件;凭据相关设置页不开放 | D286 D289 D407 |
| 右键/更多菜单 | `menus[]`(`target`:条目卡片 / 单集 / 播放页更多 / 服务器源列表项) | 插件项在官方项之后 | D157 |
| 播放页覆盖层 | `playerOverlays[]` | 默认点击穿透;声明 `interactive` 才拦截点击与焦点 | D14 D65 |
| 全局悬浮层 | `globalOverlays[]` | 都显示,按安装顺序叠;用户可在插件详情单独关;凭据页自动隐藏 | D279 D283 D407 |
| 播放页侧栏标签 | `playerPanels[]` | 选集/字幕/音轨那栏多一个标签;插件 OSD 也能打开 | D300 |
| 虚拟媒体库 | `virtualLibraries[]` | 进媒体库列表,带插件角标,可隐藏 | D473 |
| 搜索建议/快捷动作 | `searchActions`(布尔) | 官方搜索页结果列表之外 | D242 |
| 命令 | `commands[]` | 进命令面板;同名都列出并标插件名;可带参数与补全;可声明外部调用 | D243 D492 D520 D521 |
| 快捷键/遥控键 | `keybindings[]` | 可覆盖官方键;冲突在快捷键设置里选,未选前先装的生效;停用后归还 | D64 |

| 手机遥控器按钮 | `remoteButtons[]` | 扫码遥控页多一排 | D491 |
| 桌面子窗口 | `windows[]` | 手机/TV 降级为整页 | D220 D500 |
| 托盘菜单项 | `trayMenu[]` | — | D501 |
| Android 快捷方式 / 桌面小组件 / TV 推荐行 / 媒体通知动作 | `android.shortcuts[]` `android.widgets[]` `android.tvChannels[]` `android.mediaActions[]` | 小组件只能用官方模板;媒体通知最多 1~2 个动作 | D505 D506 D511 |
| 深链 | `deepLinks[]`(`linplayer://p/作者/名字/...`) | — | D154 |
| 外部输入 | `externalInputs[]`(分享 / 拖放 / 文件关联 / 剪贴板) | 多个插件匹配同一输入时让用户选 | D304 |

首页栏目的落点(D583):核心层 `plugin.homeSections` 取表、`plugin.homeItems` 取 `kind=items`
那一栏的数据;桌面画在首页最后,手机同。`kind=items` 由壳画成官方轨道的样子(主题自动跟随),
`kind=custom` 整块交给插件的 block;TV 同(D584),`custom` 那块必须套 `LocalPluginTv`,
不套的话插件的按钮不可聚焦、遥控器进不去那一行。**官方首页提前返回时照画** —— 账号不是 Emby 的那一屏
本来就只有一行说明,插件栏目正该在那时候出现。

**贡献点的表,壳必须真去要(D580 D584)。** `core/plugin/anchors.go` 里每条 `plugin.*`
取贡献表的命令,**三个壳**(桌面 / 手机 / TV)都得调 —— 不调的表现是「插件声明了入口,
界面上一个都看不见」,而三边全绿:manifest 合法、`lp check` 通过、核心层返回正确。
由 `scripts/check-plugin-ui.py` 第 5 条守着;安卓一棵树里装着手机和 TV 两个壳,
**必须分开算**,合成一个数的话手机调了就算绿(D583 的首页栏目就是这么漏了 TV 一整端)。

侧栏入口三端的落点:桌面 = 侧栏(导航项与服务器区之间);手机 = 设置根列表的「插件页面」一组;
TV = 设置页的「插件」组(导航轨按下标写死,加动态项要整个重排,暂不动)。
| 服务器类型 | `dataSource.serverTypes[]` | 出现在「添加服务器」页 | D131 D45 |
| 周期任务 / 常驻服务 | `background.tasks[]` `background.service` | 第 5.11 5.12 节 | D129 D502 |
| 注册表通道 | `registry.channels[]`(可声明推荐读者) | — | D273 D275 |

## 6.3 钩子

| 钩子 | manifest 键 | 多个时 | 预算 | 出处 |
|---|---|---|---|---|
| 导航拦截器 | `hooks.navigate` | 按用户顺序问,第一个改跳的生效 | 300ms | D277 D280 |
| 列表变换 | `hooks.listTransform`(声明作用于哪些列表) | 按用户顺序串联;可增删改排序、可插入别处条目 | 300ms | D278 D282 |
| 卡片角标 | `hooks.cardBadge` | 每张卡最多 2 个插件角标,按顺序取 | 300ms,只能用已缓存数据(同步返回) | D474 |
| 命令参数补全 | `commands[].params` 的补全 | — | 300ms | D520 |
| m3u8 过滤器 | `m3u8Filters[]` | 按用户顺序串联,单个出错/超时跳过 | 300ms/每个;删掉的分片超总时长 30% 整体放弃 | D102 D493 D494 |

**钩子的共同规则**(D281):出错或超预算就当它不存在,原数据/原路由继续;计入 D53 连错自动禁用。钩子运行在宿主屏蔽规则之前,屏蔽最后执行,插件插不回用户屏蔽的东西(D515)。钩子不作用于凭据页(D407)。

## 6.5 锚点与路由名

官方页面路由名与区块锚点名是**公开契约**,清单随 SDK 发布、改名算破坏性变更(D155)。初版清单见附录 20.3;实现时由各页面在代码里登记,门禁比对清单与代码。
