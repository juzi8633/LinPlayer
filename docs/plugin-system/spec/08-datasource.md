# 8. 数据源

数据源在界面上**就是一个「服务器」**,和 Emby 并列,有自己的首页、分类、搜索、详情、播放(D10)。页面全部由官方画,插件只供数据(D40);想自定义页面走整页接管。

## 8.1 标识

- **开放键** `plugin:<作者>/<名字>/<源id>`(D153),如 `plugin:linplayer/tvbox/a1b2c3`。源 id 由插件定,只许 `[A-Za-z0-9._-]`,**不含 `/`**;核心层按最后一个 `/` 拆出插件 id 与源 id。
- 观看记录、收藏按开放键 + 条目 id 存(D55 D153)。条目 id 对不上时(资源站换域名/改 id)按「片名 + 年份 + 集序号」找回(D55)。
- 用户写的 drpy 规则算一个数据源,不算插件:在「添加服务器」贴规则文本或地址就加上,由 TVBox 插件承载(D120 D124)。

## 8.2 插件怎么提供源

1. **服务器类型**(D131 D45):manifest 声明 `dataSource.serverTypes[]`(名称、图标、表单字段);用户在「添加服务器」选它、填表,插件 `createSources(form)` 返回一个或多个源,多个时让用户勾选要加哪几个。
   首次启动不提 TVBox/插件:首登闸口照旧只有 Emby;添加服务器页里只有装了数据源插件时才出现对应选项(D423)。
2. **动态增删**(D132 D230 D231):插件运行中可 `sources.add/update/remove`(TVBox 订阅刷新会增删源);新增的自动加入并显示;删掉的源,其收藏与观看记录**保留**。
3. **用户可改 host**:服务器列表里可手动编辑源的 host(D176),插件在 `ctx.source.hostOverride` 拿到。

每个源的配置(插件存的任意 JSON)由宿主保存,随备份与同步走(D325)。

## 8.3 动词

| 动词 | 必需 | 入参 | 返回 | 出处 |
|---|---|---|---|---|
| `detail` | 是 | 条目 id | `MediaDetail` | D260 |
| `play` | 是 | 条目、线路、集 | `PlayResult` | D256 D257 |
| `home` | 否 | — | `{ categories, recommended? }` | D167 |
| `category` | 否 | 分类 id、筛选、游标 | `Page<MediaItem>` | D255 D57 |
| `search` | 否 | 关键词、游标 | `Page<MediaItem>` | D258 |
| `person` | 否 | 演员/导演 | `Page<MediaItem>` | D168 |

- 没实现的动词,对应入口**不显示**(不做置灰,D226 D260)。
- **翻页**用不透明游标:返回 `{items, next?}`,宿主取下一页原样传回 `next`;没有 `next` = 到底(D255)。
- **取消**:离开页面或改关键词时,宿主通过 `ctx.signal` 取消进行中的调用(D166)。
- **超时**:单次 30 秒(D53)。
- **缓存**:首页/分类结果的缓存由插件自己做(KV / `cache/`),宿主不缓存(D251)。
- **限频**:宿主不限,防封归插件(D252)。

## 8.4 统一数据结构(D92 D254)

插件返回的一律是宿主的统一结构,TVBox 插件在内部把 `vod_*` 字段转过来。官方页面、聚合搜索、换源、列表钩子只认这一种。完整字段见 `api/plugin-sdk.d.ts` 的 `MediaItem` `MediaDetail` `Line` `Episode` `Season` `PlayResult`。要点:

- `MediaItem`:`id` `kind` `title` `year` `poster`(可带请求头)`backdrop` `overview` `remarks`(TVBox `vod_remarks`,显示为海报角标,D330)`ratings[]`(带来源名,D435)`externalIds`(TMDB/IMDB/豆瓣/Bangumi)`genres` `countries` `directors` `actors` `episodeCount`。
- `MediaDetail`:加 `lines[]`(线路,名字用站点给用户看的名字,D331)或 `seasons[]`(每季自带线路,D165)。
- `Episode`:`id`(不透明,原样交回 `play`)`name` `index`(可选;没给宿主从名字解析)。
- `PlayResult`(D256):`url` + `headers`;可选 `qualities[]`(多清晰度,可切,切换保持进度)、`subtitles[]`(地址+语言,宿主 `sub-add`)、`skip`(片头结束/片尾开始秒数)、`danmaku`(源自带弹幕,作为这一集的一个弹幕源,默认开,D433)、`useProxy`(子请求也要带头时走宿主代理,D37)。
- 分类:`id` `name` `posterShape`(`portrait` 2:3 默认 / `landscape` 16:9 / `square`,宿主按比例换网格列数,D336)`filters[]`(维度 `key` `name` `multi`(单选/多选,D334)`options[]`)。
- 数据源声明 `disablePrefetch`(有的站多连接会封,D173)。

## 8.5 解析与嗅探归插件(D257)

`play()` 必须返回**最终可播地址**。要解析(parses)、要嗅探就在 `play()` 里自己调 fetch 与 WebView;宿主没有「解析」概念。播需要解析的片时,插件可在播放页侧栏挂「解析」标签让用户手选换一个重试(D377)。

## 8.6 错误(D253 D323)

插件抛 `PluginError`,`kind` 决定宿主显示的文案与动作:

| kind | 文案(示意) | 动作按钮 |
|---|---|---|
| `needVerify` | 站点需要验证 | [去验证]:开整页 WebView 过盾,Cookie 进该源罐子后自动重试 |
| `needLogin` | 需要登录 | [去登录]:跳插件声明的登录页/设置 |
| `rateLimited` | 请求太频繁 | [N 秒后重试]:用 `retryAfter` 倒计时 |
| `siteDown` | 站点不可用 | [换源] (D232) |
| `notFound` | 没找到 | — |
| `parseFailed` | 解析失败 | — |
| 其它 | 见附录 20.2 | — |

**「未找到」与「限流」必须分开**(弹弹 Play 把 429 显示成「未找到」查了几个月)。首页请求失败时服务器列表里该源标红「上次访问失败」(D122)。

## 8.7 宿主侧页面行为

### 服务器列表与切换
- 数据源与 Emby **同一套卡片**,右上角来源角标(Emby / TVBox / 插件名),图标可用服务器图标库(D225 D126)。
- 列表按来源分组:Emby 一组、每个 TVBox 订阅一组(可折叠)、插件源一组;可拖动排序、可隐藏(D123)。
- 切换器:按分组折叠(订阅组默认折叠)+ 星标收藏源一组置顶 + 最近切过的 5 个置顶;不做搜索框(D383)。
- 健康度只显示失败标红(D384);「一键检测全部源」:并发 8,调 `home`(没有则首个分类),拿到列表即算活,不测播放地址;不做启动时自动检测(D122 D385)。
- 数据源条目可被屏蔽(分类、关键词),复用媒体库屏蔽与集中解除列表(D516)。

### 首页(D167 D175 D344)
顶部「继续观看」(该源的在看)→ 源的推荐行(`home.recommended`)→ 分类入口。与 Emby 首页「媒体库 + 最新」结构对齐。源没实现 `home` 就直接显示第一个分类(顶部分类标签默认选中第一个);分类也没有就只有搜索框。

### 分类页
- 筛选复用 Emby 媒体库筛选面板(D57 D334);筛选按「源 + 分类」记住,生效时分类标题旁小点 + 一键清除(D335)。
- 滚到底加载下一页(D166)。海报比例按分类声明(D336)。缺海报显示统一灰色占位(D341)。同源重名条目原样显示(D524)。

### 搜索
- 源内搜索:停顿 500ms 自动搜,改关键词取消进行中的请求(D338 D166)。
- 聚合搜索(搜索页):**按回车/按钮才发**;按源分行、每源最多 8 条、谁先返回谁先显示(D258 D262)。只包括「允许聚合」的源(D235)。
- 搜索历史全局一份(Emby 与数据源共用),最多 50 条,可单条删/清空,进备份与同步(D339)。

### 详情页
- 有横版背景图(源自带或元数据插件补到)用与 Emby 相同的背景布局;没有就用左海报右信息的无背景布局(D337)。
- 简介宿主统一去 HTML 标签转纯文本、保留换行(D462)。
- 顶部一排线路标签,切换后选集格跟着变(D54);再次打开默认上次的线路,按剧记线路名,线路没了退回第一条(D343)。
- 选集格:集名统一显示成「第 N 集」;解析不出序号的(「正片」「花絮」)和日期型集名(综艺)原样显示(D461);可正序/倒序切换,每部剧记住(D332);集多时按 1-50 / 51-100 分页(D165);有季结构时先选季(D165)。
- 只有一集(电影「正片」)时不显示选集格,只有播放按钮,线路标签照留(D463)。
- 演员/导演:源实现了 `person` 就可点进演员页;没实现就点了在当前源搜这个名字;也没 `search` 就是纯文字(D168 D340)。
- 数据源没有的能力(媒体库筛选、演员页、官方下载器、服务器端收藏同步……)入口直接不显示(D226)。

### 播放
- 直链走预取代理,m3u8 按现有规则;源声明禁用预取就直连(D173)。
- 播放页内也能切线路,保持当前集数与进度;线路间集数不一致时**按集序号对应**,目标线路没有这一集就提示并留在原线路(D54 D464)。
- 自动下一集:同线路、按选集格顺序(不受倒序显示影响)、跟随 Emby 的连播设置,最后一集就停;插件接了「下一个播什么」就听插件(D460 D244)。
- 片头片尾:`play()` 给了就用;否则播放页菜单「跳过片头 N 秒 / 片尾 N 秒」按整部剧记住(D342);片头片尾提供者插件也可补(D537)。
- 播放失败**不自动切线路**,直接弹换源列表(D263)。

## 8.8 聚合与换源

### 「允许聚合」开关(D233 D235)
每个服务器/源一个开关,一个开关管所有聚合:关了就不进聚合搜索、聚合视界、换源。默认:Emby 开;TVBox 源跟随配置的 `searchable`(=1 开);其它插件源关。

### 换源(D232~D236 D259 D261 D525)
- 详情页与播放页都有「换源」按钮,**Emby 的片也有**(如 Emby 还没更新到最新集时跳去数据源看);这是跳转,不是把数据源塞进 Emby 详情当线路(D10)。
- 三层,默认顺序:① 当前源的其它线路(Emby 片是同一条目的其它版本);② 允许聚合的数据源;③ 允许聚合的 Emby 服务器。**用户可调三层顺序**。
- 并发上限 8,单源超时 8 秒,结果边出边显示。
- 排序:层级在最外;层内按相似度分三档「同一部 / 可能是 / 不像(折叠到底部)」,相似度 = 片名完全一致 > 年份一致 > 集数接近 > 包含关键词;档内按该源接口响应耗时。
- 跳过去**带上播放进度**(同一集从当前位置接着播;片头长度不同可能差几秒)。这是用户主动的,不违反「数据源进度不进跨服续播」(D174)。

### 聚合视界(D429)
允许聚合的数据源在聚合视界里**只显示继续观看**;没在看的源不占位置。

## 8.9 观看记录与收藏

- 数据源享受官方的观看记录/续播、收藏、弹幕匹配;**不接官方下载器**(D20 D25)。
- 数据源进度只在该源内有效,**不进跨服续播**(D174)。
- 「继续观看」出现在该源自己的首页顶部 + 全局「观看历史」页;不混进 Emby 首页(D175)。
- 全局观看历史按时间混排,卡片带来源角标,顶部可按来源筛选(D430)。同一部片因换源在多个源都有记录时**合并成一条**,取进度最远的那条,点开从那个源续播;关联靠换源链路记录,不靠片名猜(D431)。
- 收藏跟当前服务器走;全局「观看历史」旁有「全部收藏」汇总各源(D326)。
- 卸载数据源插件或删订阅后,收藏与观看记录**永远保留**,观看历史里灰显「来源已移除」,点击触发换源(D333)。
- Android TV 启动器的「继续观看」由宿主写,包含数据源的在看(D510)。
