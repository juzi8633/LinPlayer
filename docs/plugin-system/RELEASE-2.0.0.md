# LinPlayer 2.0.0 发布说明(草稿)

> 这份是 2.0.0 的**人写的**那部分。每次构建的提交清单由 `scripts/release-notes.sh`
> 从提交历史生成,两者在 Release 页面里拼在一起 —— 上半段说「这一版是什么」,
> 下半段说「具体改了哪些」。

## 这一版是什么

**LinPlayer 能装插件了。**

在这之前,想加一个功能就得等我们做。2.0.0 之后,播放器本身开放了一套扩展点:
一个插件可以往详情页塞一块内容、在播放器里加一层自己的界面、接一个新的数据源、
换掉整套主题、甚至加一个官方没有的页面。插件用 TypeScript 写,界面用 JSX,
跑在应用内部的 JS 运行时里,渲染出来的是**原生控件** —— 不是网页套壳,
在电视盒子上也一样跟手。

### 随 2.0.0 一起发的官方插件

| 插件 | 做什么 |
|---|---|
| **TVBox 源** | 吃 TVBox 配置:整份导入、解析接口(type 0/1/2/3)、jar 与 drpy、WebView 嗅探、去广告规则 |
| **直播** | 贴一条 m3u / txt 就能看;同名频道合并成「源 1/2/3」,播不动自动换下一条并记住能用的那条;XMLTV 节目单、回看与时移;电视上按 TVBox 的习惯操作(上下换台、数字键输号、确认呼出列表) |
| **Trakt / Bangumi 同步** | 看的时候自动记账,看完自动标记;详情页显示同步状态;收藏与集数进度管理 |
| **字幕翻译** | 把当前字幕翻成你看得懂的语言(用你自己的 API key);没有字幕时可以先用 Whisper 转写;还能边播边翻 |
| **规则编辑器** | 在应用里写、跑、调数据源规则,不用来回改文件重启 |
| **午夜蓝主题**(桌面 / 手机 / TV 各一套) | 示范一个主题包能改什么 |
| **开发者工具** | 日志、网络、界面树、性能与存储四块面板 —— 写插件时用 |

### 给想写插件的人

```bash
pnpm add -D @linplayer/cli @linplayer/plugin-sdk
pnpm lp new my-plugin
pnpm lp dev        # 连上正在运行的 LinPlayer,改完即时生效
```

- 接口文档与全部扩展点清单在开发者站上;每个扩展点都有一个几十行的最小示例。
- `pnpm lp check` 在本地跑的,就是上架时 CI 跑的那一套校验。
- 插件装在哪、能干什么、拿不到什么,都写在「插件与安全」那一页 ——
  **插件拿不到你的 Emby 账号密码**,这一条是设计里钉死的,不是靠自觉。

## 升级须知

- 2.0.0 是大版本,配置会自动迁移,**不需要重新登录**。
- 从 1.x 升上来之后,原来内置的 TVBox 支持变成了「TVBox 源」插件,
  它随应用预装,已有的配置照旧可用 —— 不用重新导入。
- 主题切换要重启生效,壁纸切换不用。

## 已知的没做到

写在这儿而不是藏着:

- **桌面暂时不放视频壁纸**,静态图和程序生成的动态壁纸都正常。
  原因是视频壁纸要第二条 GL 通道,而一个进程只能有一条 —— 要动的是更底下的地基,
  没赶上这一版。挑了视频壁纸的包时会显示它的封面帧,并且会告诉你这一端只放第一帧。
- **手机上插件收不到遥控器按键**(手机本来也没有);电视和桌面正常。
- 插件页里的 `<Player>` 组件这一版仍是占位,内嵌播放要等下一版。
