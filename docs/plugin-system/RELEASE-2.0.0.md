# LinPlayer 2.0.0 发布说明

> 这份是 2.0.0 的**人写的**那部分。每次构建的提交清单由 `scripts/release-notes.sh`
> 从提交历史生成,拼在下半段 —— 上半段说「这一版是什么」,下半段说「具体改了哪些」。

## 先说重要的:这一版有东西挪了位置

2.0.0 把几个原来内置的功能改成了**插件**。升级之后它们**不会自动出现** ——
要到「设置 → 插件」里装一次(免费,官方源,一键)。
不装也不影响看片,但你会发现原来的入口没了,所以先把话说在前面:

| 原来在哪 | 现在在哪 | 升级后要做什么 |
|---|---|---|
| 设置里的「字幕翻译」 | 官方插件「字幕翻译」 | 想用就装一次;你的 API key 要重新填 |
| Trakt / Bangumi 的**自动记录进度、标记看完、收藏管理** | 官方插件「Trakt / Bangumi 同步」 | 想用就装一次。**账号不用重连**,连接入口还在设置里 |
| 「发现 / 影视目录」页 | 数据源插件自己画自己的页面 | 装了「TVBox 源」之后在插件页里进 |
| 1.x 的旧插件(`com.linplayer.*` 那一批) | **没了,不兼容** | 旧插件和它们存的数据在升级时会被清掉,新版插件要重装 |

**没有动的**(有人担心过,这里说清楚):排行榜、付费追剧日历、弹幕、
Emby 与各种源的浏览与播放、下载、预取与多线程加载、跳过片头片尾、
备份与还原、扫码搬迁 —— 都还在宿主里,位置也没变。

## 这一版是什么

**LinPlayer 能装插件了。**

在这之前,想加一个功能就得等我们做。2.0.0 之后,播放器本身开放了一套扩展点:
一个插件可以往详情页塞一块内容、在播放器里加一层自己的界面、接一个新的数据源、
换掉整套主题、甚至加一个官方没有的页面。插件用 TypeScript 写,界面用 JSX,
跑在应用内部的 JS 运行时里,渲染出来的是**原生控件** —— 不是网页套壳,
在电视盒子上也一样跟手。

### 随 2.0.0 一起上架的官方插件

九个,都在「设置 → 插件 → 市场」里,免费:

| 插件 | 做什么 |
|---|---|
| **TVBox 源** | 吃 TVBox 配置:整份导入、解析接口(type 0/1/2/3)、jar 与 drpy、WebView 嗅探、去广告规则 |
| **直播** | 贴一条 m3u / txt 就能看;同名频道合并成「源 1/2/3」,播不动自动换下一条并记住能用的那条;XMLTV 节目单、回看与时移;电视上按 TVBox 的习惯操作(上下换台、数字键输号、确认呼出列表) |
| **Trakt / Bangumi 同步** | 看的时候自动记账,看完自动标记;详情页显示同步状态;收藏与集数进度管理 |
| **字幕翻译** | 把当前字幕翻成你看得懂的语言(用你自己的 API key);没有字幕时可以先用 Whisper 转写;还能边播边翻 |
| **规则编辑器** | 在应用里写、跑、调数据源规则,不用来回改文件重启 |
| **午夜蓝主题**(桌面 / 手机 / TV 各一套) | 示范一个主题包能改什么 |
| **开发者工具** | 日志、网络、界面树、性能与存储四块面板 —— 写插件时用 |

### 插件拿不到什么

- **拿不到你的 Emby 账号密码**,也拿不到 Trakt / Bangumi 的 token ——
  需要用服务器身份发请求时,插件把请求交给宿主代发,token 不经过插件。
- 每个插件有自己的存储沙箱,互相读不到。
- 装之前会列出它要的权限(联网、哪些域名、读哪些数据),不点同意就不装。
- 插件跑超时会被掐断:界面 1 秒、取数 30 秒、钩子 300 毫秒。
- 启动连崩两次自动进安全模式,把所有插件停掉 —— 不会让一个插件把播放器带死。

### 给想写插件的人

```bash
pnpm add -D @linplayer/cli @linplayer/plugin-sdk
pnpm lp new my-plugin
pnpm lp dev        # 连上正在运行的 LinPlayer,改完即时生效
```

- 接口文档与全部扩展点清单在开发者站上;每个扩展点都有一个几十行的最小示例。
- `pnpm lp check` 在本地跑的,就是上架时 CI 跑的那一套校验。
- SDK 与官方插件整仓 AGPL-3.0-or-later。**这不要求你的插件也用 AGPL** ——
  依赖它的类型定义写自己的插件,许可证你自己挑。

## 升级须知

- 2.0.0 是大版本,配置会自动迁移,**不需要重新登录**。
- 原来内置的 TVBox 支持现在是「TVBox 源」插件。**它不随安装包附带,要装一次**,
  装完已有的配置照旧可用 —— 不用重新导入。
- 主题切换要重启生效,壁纸切换不用。
- 装插件要能连上官方插件市场。完全离线的机器这一版装不了插件。

## 已知的没做到

写在这儿而不是藏着:

- **桌面暂时不放视频壁纸**,静态图和程序生成的动态壁纸都正常。
  原因是视频壁纸要第二条 GL 通道,而一个进程只能有一条 —— 要动的是更底下的地基,
  没赶上这一版。挑了视频壁纸的包时会显示它的封面帧,并且会告诉你这一端只放第一帧。
- **手机上插件收不到遥控器按键**(手机本来也没有);电视和桌面正常。
- 插件页里的 `<Player>` 组件这一版仍是占位,内嵌播放要等下一版。
- 官方插件**不随安装包附带**,首次使用要联网装一次。
