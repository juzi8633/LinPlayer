# 插件系统 SPEC(草案,问答中持续完善)

> 从零重做,不参考旧插件系统。外部调研正本在 `docs/research/plugins-v2/`。
> 本文只记**已拍板的决定**和**还没拍板的问题**;被推翻的决定直接删。

## 0. 原则

- **不必要的东西不内置,做成插件。** 宿主只放"插件做不了"或"所有人都要"的能力(用户 2026-09-19:"没必要内置不必要的东西到软件里面")。

## 2. 待定问题(附当前提案)

### 2.1 UI 协议:提案

- (写法见 D23)自定义 reconciler 把组件树变成 JSON,宿主收 **整树首帧 + 增量 patch**,事件回传 JS。
- 官方基础组件两端各实现一遍(布局/文本/图片/按钮/输入/列表/网格/海报卡……);插件"自己写组件" = 用基础组件组合。
- 官方页面预留**命名插槽**,插件可替换某个区块;整页接管 = 替换整个路由。
- 主题 = 覆盖 `Theme/Tokens.axaml` 那套 token(两端运行时替换)。
- 自绘见 D19。
